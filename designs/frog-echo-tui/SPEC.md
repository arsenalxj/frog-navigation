# 青蛙导航 · 回声终端 — 复刻规格

命令行为核心的浅色 TUI：操作与配置均在命令行或全屏缓冲区中完成，不使用弹窗。增删改、设置、备份恢复、目录切换与自定义命令共用底部命令入口。所有界面以 **SVG 1440 × 900** 绘制，坐标即设计稿坐标。

## 2. 画板与栅格

- 1440 × 900；页面即应用主界面：全出血、无外框、无桌面衬底，窗口尺寸变化时等比缩放居中。
- 无独立顶栏（品牌、计数等装饰或与状态栏重复）；列表 `y=24` 起；命令行 `752..792` 通宽；状态栏 `796..832` 通宽墨绿条；按键条 `y=856`。
- 主界面为单列表，列表与日志横跨 `x=40..1400`；添加与设置只用键位（`a` / `,`）和命令（`:add` / `:set`），没有常驻按钮。
- 列表无表头：行从 `y=24` 开始；行高 32；可视 19 行（`24..648`），单页滚动、不分页；日志 `x=40, y=664, w=1360, h=72`。
- 文件夹在根目录原地展开／折叠，子书签缩进显示并带连接线；不再进入独立文件夹视图，也没有面包屑。列表固定可视 19 行，展开后单页滚动。列表不显示行号。搜索结果跨文件夹，平铺显示。
- 缓冲区使用相同全宽范围 `x=40..1400, y=24..736`。
- 字体 `"SF Mono", "JetBrains Mono", Menlo, Consolas, "PingFang SC", monospace`；正文 14–15.5，底部日志与状态区 11.5–12.5，元信息 10.5–12，标题 18。

## 3. 命令行模型

命令行永远在底部，`:` 进入命令模式，显示内置与自定义候选；Tab 补全，↑↓ 显式选择，⌥↑↓ 历史，Enter 执行完整命令或显式选中项，Esc 取消。候选可按名称或说明筛选，点击仅补全，不直接执行。
空闲时把操作提示作为占位符放在输入起点（`: 打开命令 · / 搜索 · ? 帮助`），与真实输入共用同一左侧起点，不额外绘制假光标；只有在输入或提示流中，右侧才显示当前可执行动作。设置页占位符只提示命令入口与 `:help`。

| 命令 | 行为 |
| --- | --- |
| `:add` | 三次提示：url → title → location（分组补全，可选新建文件夹）；结束后写入并记日志 |
| `:edit [url\|title]` | 标题与网址以当前值预填；Tab/Shift+Tab 切换字段并保留草稿，Enter 一次保存两项，Esc 全部取消。`e` 从标题开始，`:edit url` 直接从网址开始 |
| `:rename` | 文件夹名预填，Enter 提交 |
| `:mkdir [名称]` | 新建空文件夹（建在根目录，自动选中）；不带名称时提示输入；重名拒绝。`n` 等同 |
| `:delete` | 命令行确认 `y/N`，直接显示目标名称 |
| `:move` | 目标位置补全（根目录/分组/新建文件夹）；选「新建文件夹…」后先输入名称，再创建并移入；Shift+Tab 返回目标选择 |
| `:open` / `:copy` | 打开当前项 / 复制链接 |
| `:group <名称>` / `:find <词>` | 展开并定位文件夹 / 搜索；`:group 根目录` 折叠全部 |
| `:calc` / `:calc clear` | 打开计算器缓冲区 / 清空算式与历史；`calculator` 等同 |
| `:set [key] [value]` | 无参数打开设置缓冲区；`login / hotkey / corner / finder / data` |
| `:set hotkey record` | 下一组按键即绑定；冲突写入日志与设置缓冲区 |
| `:set corner <位置>` | 位置使用 `left-down / left-up / right-up / right-down`；非法值不改变当前角落 |
| `:backup [文件路径]` / `:restore <备份文件>` / `:cd <目录>` | 导出书签 JSON 副本 / 从备份整体恢复 / 切换 `bookmarks.json` 的存放目录；过程与结果在任务缓冲区展示 |
| `:help` / `:log` / `:retry` / `:clear` / `:q` | 缓冲区与维护命令 |
| `:commands` / `:aiomp` | macOS 自定义命令管理缓冲区 / 预置 OMP 命令执行预览 |

新增提示流中：Tab/↑↓ 在候选间切换并回填，Enter 确认，Esc 取消；**仅 Shift+Tab 返回上一步**。Backspace 只删除文字，字段为空时也不切换步骤。返回时保留尚未按 Enter 的标题、新文件夹名称和已选位置。删空筛选条件会恢复全部候选，当前候选始终滚动到可见范围。编辑时 Tab/Shift+Tab 切换标题与网址，两个字段验证通过后才一起保存；校验失败保留全部草稿并定位错误字段。

进入编辑、切换标题/网址、返回上一步及重命名时，光标默认在文本末尾，不自动全选。未主动选择文字时，Backspace 只删除光标前一个字符；需要整段替换时使用 Cmd/Ctrl+A 显式全选。新增流程的预填标题沿用相同行为。

浏览时点击书签整行（包括空白区域）会选中该项并把键盘焦点交给列表；如果此前在搜索/命令输入，结束输入模式但保留搜索结果，随后 `e/m/a` 按快捷键处理。在编辑/新增提示流中，字符键只编辑文字，点击背景行不会重定向草稿或丢失输入焦点；先 Enter 提交或 Esc 取消，再选择其他书签。

## 4. 缓冲区（替代弹窗）

- **settings**：`~/.config/frog/config.toml` 风格，带行号，使用“设置项 / 当前值 / 命令”三列；三列文字起点为 `x=130 / 304 / 840`，当前值可用宽度 496px，和命令列之间预留 40px。超长值在列内省略，悬停行时显示完整值，不改变实际设置。角落改值后在原位置高亮并显示箭头 900ms，连续修改从最后一次操作计时。权限缺失、登录待批准、快捷键冲突等状态以 `# !` 注释行呈现。
  - `[data] · 书签数据`：`file` 显示正在使用的 `bookmarks.json` 完整路径，默认文件路径完整显示。`:cd <目录>` 切换存放目录，文件名固定；帮助页同步显示当前 JSON 文件。
  - `[operations] · 数据操作`：用用途说明和命令展示操作，不作为配置键值。导出备份另存书签与文件夹 JSON；恢复备份明确提示替换当前全部书签与文件夹。备份不改变当前文件位置，设备偏好不进入备份。
  - 设置命令格式、帮助与返回提示统一放在右下角状态栏：`:set <key> <value> · :help 帮助 · Esc 返回`；标题行只显示缓冲区名称。设置页状态栏左侧只显示当前模式。浏览状态栏不再显示固定位置与行数；有展开文件夹时显示“已展开 N 个文件夹”，搜索时显示查询与结果数。
- **calc**：`:calc` 打开。命令行输入算式，支持数字、`+ - * /`、小数点、空格与小括号；算式与结果使用等宽字体与等宽数字，字符步进一致；输入法打出的中文括号 `（）` 自动转换为英文括号；`Enter` 或 `=` 计算，结果实时预览并写入历史。↑/↓ 按列表顺序移动历史选择（↑ 上、↓ 下）并把选中项回填到命令行，点击历史项即选中并载入；选中历史项时 `c` 复制该条结果，未选中时复制当前算式结果，右侧短暂提示复制内容；Esc 关闭后保留算式与历史，再次 `:calc` 恢复。`:calc clear` 清空全部。历史最多 50 条，完全相同的算式只保留最新一条；结果按 12 位有效数字输出，指数形式结果可直接回填；算式长度上限 256 字。除以 0、括号不匹配与不完整算式在结果区提示且不写入历史，继续编辑即清除错误。
- **help**：man page（NAME/SYNOPSIS/COMMANDS/KEYS/EXAMPLES/FILES）。
- **job**：备份/恢复/目录切换的命令、过程、结果与退出码，RUNNING/DONE/ERROR 标签。
- **log**：完整事件日志，时间 + 级别颜色。

## 5. 界面与状态（48 帧）

主流程 11：根目录、文件夹展开／折叠、搜索/输入/无结果、空库、空文件夹（展开后无子项）、载入、损坏、目录不可用、冲突。
整理与拖拽 4：整理模式、排序、拖入文件夹、创建文件夹。
命令行 15：add 三步与新文件夹、edit 标题/网址、delete 确认、rename、mkdir、move 目标/新文件夹名称、backup、restore、cd、hotkey。
缓冲区 11：设置（默认/登录待批准/登录失败/快捷键冲突/触角失败/快跳缺权限/Finder 读取失败）、帮助、计算器、日志、自定义命令。
任务输出 5：备份成功/失败、恢复校验失败/成功、目录权限失败。
系统 2：Finder 目录浮条（有/无目录）。

错误不再用横幅：写入日志（3 行常驻）+ 需要时 `:log` 查看全部。

## 6. 键盘

`j/k` 或 `↑/↓` 选择 · `g/G` 首尾 · `PgUp/PgDn` 上/下一屏 · `Enter` 打开书签或切换文件夹展开 · `Tab` 展开／折叠文件夹 · `z` 全部展开／折叠 · `/` 搜索 · `:` 命令 · `a` 添加 · `n` 新建文件夹 · `e` 编辑 · `r` 重命名 · `m` 移动 · `D` 删除 · `C` 复制 · `o` 整理 · `,` 设置 · `?` 帮助 · `Esc` 逐层折叠与返回。浏览时数字键 0–9 不执行打开或切换。输入字段内的数字正常作为文字输入。
列表只有一页：条目超出可视区时，滚轮或 `PgUp/PgDn` 滚动，选中项始终保持在可视区内，不出现分页控件。

原生 macOS 的底部按键条按“执行中 → 提示流 → 命令／搜索输入 → 缓冲区 → 列表”取当前上下文，不叠加底层模式按键。提示流区分命令与步骤；候选存在时才显示补全／选择，能够回退时才显示 Shift+Tab。浏览区分书签与文件夹、展开与折叠，搜索输入和点击结果后的列表操作分别提示；整理只对书签显示排序键。设置、帮助、日志、任务和计算器使用各自的按键条，执行中显示等待提示。输入或执行期间，状态栏隐藏底层页面的命令／帮助入口；Esc 文案对应实际的取消、返回、折叠或收起动作。

原生 macOS 选中单条书签时可按 `c` 或 `C` 复制完整网址，底部统一显示 `c 复制链接`，普通浏览、搜索结果点击选中后及整理模式均可用；选中文件夹不显示复制提示。搜索、命令和编辑输入中的 `c` 按文字处理，计算器中的 `c` 仍复制计算结果。

设置缓冲区：`:` 输入命令，`:help` 查看帮助，`Esc` 取消当前输入或返回书签；普通字符不触发操作，也不会落入主列表快捷键。设置页不显示快捷键侧栏和主列表底部按键条。快捷键录入通过 `:set hotkey record` 开始，再按组合键保存；其他缓冲区保留 `Esc` 返回。

计算器缓冲区：数字、`+ - * / ( ) .` 与空格直接输入，其他字符不进入输入框；中文括号在输入或输入法提交后转为英文括号；`Enter` 或 `=` 计算；`↑/↓` 按列表顺序切换历史选择并回填；`:` 输入命令；`Esc` 关闭并保留算式与历史。`←/→`、`Home/End` 移动光标，SVG 光标跟随真实位置；`c` 复制选中历史结果或当前结果；`Shift+方向键` 或 `⌘A` 的选区以鸦黄底显示，退格与输入作用于当前光标或选区；点击命令行任意位置都会回到算式输入。计算器同样不显示主列表底部按键条。

根目录始终先显示全部文件夹，再显示独立书签；文件夹保留原有顺序、位置固定，不参与整理排序。展开状态只影响显示，不改变顺序，也不参与排序。`o` 进入整理后，`j/k` 只改变选中项，`Shift+↑/↓` 或 `K/J` 仅将当前书签向上/下移动一位，根目录书签不会越过置顶文件夹，子书签只在同一文件夹内排序。移动后选中项跟随该书签，滚动位置自动保证其可见，首尾边界不循环。`m` 移动书签到文件夹，`D` 或书签行内 `[×]` 删除对应项（需确认）；文件夹仍可重命名，空文件夹可用 `D` 删除。`o/Esc` 完成整理，保留已调整顺序；搜索结果无法排序，需先清空搜索。

文件夹展开状态保存为本机显示偏好（`frog.expandedGroupIDs`，文件夹 id 列表），不进入书签数据或备份；删除文件夹后自动丢弃，首次启动默认全部折叠。

## 7. 原型边界

书签数据在内存中，刷新重置；打开只写日志不跳转；备份/恢复/目录切换为模拟任务；权限、登录项、Finder 读取以状态文本呈现。计算器的算式与历史同样只保存在内存中，刷新重置；关闭计算器不丢失，再次打开恢复原算式与历史。自定义命令单独保存到本浏览器 localStorage，刷新保留，不访问正式应用数据；执行仅显示计划，不调用 shell、不打开网址或应用，也不验证本机目录及程序。

书签图标固定采用本地生成的「标题首字符 + 传统色底板」（20×20，3px 圆角）：英文字母大写，中文保留首字，底色由书签 ID 稳定映射；修改标题后首字随之更新，底色不变。此方案用于最终界面，不下载、缓存网页图标，也不提供图标刷新命令。

JSON 格式与持久化规则参考 `plans/PLAN_MACOSAPP.md`；本原型的命令交互与图标方案以本规格为准。macOS 使用 AppKit 原生绘制与静态 SVG，Windows 使用 Win32 / Direct2D / DirectWrite 对齐同一终端布局与交互；Windows 不实现文件夹快跳。各平台实际验证边界见对应 `VALIDATION.md`。

自 2026-11-05 起取消“进入文件夹”，交互以 `designs/frog-tree-expand` 的全映射原型为准；本目录的 JSX/Playwright 用例仍保留旧的进入流程与 atlas 命令地图，作为历史对照，不再代表当前产品交互。

2026-11-07 新增的 macOS 自定义命令在本目录完整命令原型中评审；命令管理与执行预览以本规格第 10 节为准。此次不改变树形展开方案，也不将本目录的旧书签浏览行为重新作为产品标准。

## 8. 文件

- `tokens.jsx`：色板、栅格、命令表、键位。
- `icons.jsx` / `ui.jsx`：SVG 图标与命令行/日志/状态栏外壳。
- `calc.jsx`：算式解析（+ - * / 与括号）与结果格式化。
- `screens-main.jsx`：全宽单页滚动列表、文件夹入口、空态、整理与拖拽。
- `screens-buffers.jsx`：设置/帮助/计算器/日志/任务缓冲区 + 系统文件面板 mock。
- `commands.jsx`：macOS 命令候选、配置管理、本浏览器存储与执行计划预览。
- `app.jsx`：命令引擎、提示流、计算器状态、缓冲区路由、键盘、场景。
- `?scene=<id>` 或 `frogJumpScene("<id>")` 直达状态帧。

## 9. 浏览器交互回归

- `interaction.spec.mjs`：使用 Playwright 的真实鼠标与键盘事件，覆盖全宽单页列表（首尾同屏、无翻页控件）、文件夹置顶与位置固定、Enter/Tab 展开折叠与 Esc 分层折叠、数字键无导航行为、点击后的焦点交接、编辑与移动、候选恢复与滚动、Shift+Tab 草稿往返、标题/网址联合保存与取消、无效网址拦截、书签排序与整理后选中跟随、删除目标正确性。退格用例直接进入预填字段后按键，覆盖首次编辑、字段切换/返回、中文名称、中间位置删除、新增与重命名，并单独验证显式全选。计算器覆盖四则运算与括号优先级、除以 0 提示、字母不进入算式、历史 ↑/↓ 与草稿恢复、点击历史项载入、关闭后重新打开保留算式与历史、`:calc clear` 清空。每个用例使用独立浏览器上下文，不调用 `frogJumpScene`、不直接修改 React 状态。

## 10. macOS 自定义命令原型

- 直达：`?scene=buffer-commands`；正常入口为 `:commands`，设置与帮助页也显示该命令。
- 视觉对齐 `calc`：复用 `bvTitle`、`CommandChrome`、`StatusChrome`，内容左右边界为 `x=72..1368`；顶部 40px 深绿主信息，`y=168` 分隔线、`y=192` 小号区段标题，列表自 `y=216` 起按 26px 行距排列。选中行使用 22px 墨黑底与 3px 鸦黄标记，最多显示 16 行。列表、编辑、预览、删除确认沿用同一骨架。
- 配置字段与执行计划使用无边框文字行；操作使用区段标题右侧的可点击快捷键文字，搜索与编辑进入底部共用命令行。底部只保留共用状态栏和缓冲区脚注，与计算器一致。
- 预置 `:aiomp`（在青蛙项目目录运行 `omp`）、`:codefrog`（通过 `/usr/bin/open` 打开 VS Code）、`:gh <查询>`（GitHub 搜索）。仅展示执行计划，不宣称启动成功。
- 列表：↑↓ / j/k 选择，`/` 按命令名与说明搜索，`a` 新增，`e` 编辑，`c` 复制，`D` 删除，Enter 试运行预览。整行可点击选中，双击编辑；删除需 y 确认，n / Esc 取消，仅删除配置。
- 配置：命令名、名称、动作类型；终端／程序动作配置工作目录、执行内容、参数模板与终端；网址动作仅显示网址模板。原型的 Tab 切换字段仅用于网页预览；原生实现为字段模式 `↑↓` 切字段、目录字段 `Enter` 进入浏览（见第 10 节原生补充）。⌘Enter 保存，Esc 丢弃草稿。进入预填字段时光标位于末尾，不隐式全选。
- 校验：命令名以字母开头，仅含字母、数字、短横线、下划线；不区分大小写判重，保留内置命令及别名。名称与执行内容必填，工作目录使用绝对路径或 `~/`，网址限 HTTP / HTTPS。
- 参数：网址 `{query}` 替换时进行 URL 编码；终端／程序预览分别展示模板与原始输入数据，不拼成可执行 shell 字符串。真实原生执行器与参数解析不属于本轮原型。
- 终端候选：Terminal、iTerm2；程序／脚本另可选择“不使用终端”。原型不探测安装情况。
- 存储键：`frog-echo-macos-commands-v1`，首次使用提供三条示例，删除全部后保持空列表。读取错误时提示并禁止覆盖原值；写入错误保留草稿。
- 本轮浏览器验收覆盖：OMP 预览、候选补全与显式选择、未知命令不执行、创建与复制、刷新保留、筛选、删除取消／确认、保留名拦截、预填退格与字段往返、中文空格目录、网址特殊字符编码。未进行真实 macOS 进程执行验收。
- 原生 macOS 已落地：`:commands` 使用同一视觉骨架，Enter 与 `:<名称>` 真实执行，不再显示“仅预览”；结果区使用 `EXECUTION`，分别报告终端／浏览器交接和无终端程序的实际退出状态。首次为空列表，配置单独保存到本机 `commands-macos.json`；操作、参数语义与真实验收见 `macos/README.md`、`macos/VALIDATION.md`。本目录网页仍是安全的非执行原型。
- 原生终端字段通过系统应用注册信息发现已安装的 Terminal／iTerm2／Ghostty，仅在可用项间切换；缺失的已保存终端保留并标识“未安装”。Ghostty 优先通过脚本接口在运行中的当前窗口新建标签页（工作目录、命令、命令结束后保留标签），未运行或脚本失败时才启动禁用窗口状态恢复的独立实例；其他终端打开私有 `.command`。
- 原生工作目录分字段模式与浏览模式：字段模式 `↑↓` / `Tab` 切字段，目录字段按 `Enter` 才进入浏览；浏览模式 `↑↓` 只移动高亮，`Tab` 选择并进入目录，`⇧Tab` 返回上一级并预选刚离开的目录，`Enter` 退出浏览并保留当前路径（不应用高亮项），`Esc` 退出浏览并恢复原路径，直接键入则自动退出浏览。区域标题显示 `READY` / `BROWSING`，字段行右侧同步标识。配置字段下方 `y=394` 分隔线、`y=414` 标题，候选从 `y=444` 起按 26px 行距显示，最多 10 行并随选择滚动。相对路径基准在本次编辑期间固定并显示于脚注；保存时规范化为绝对路径。网页原型不读取本机文件系统。
