# 青蛙导航 原生 macOS 应用

此目录提供 macOS 14 及以上的本地书签启动台，采用 AppKit 原生交互与绘制，静态图标使用本地 SVG 资源，不嵌入 WebView。

- `Sources/FrogCore/`：模型、数据存储、同步文件监听与可测试的纯逻辑；文件名采用 Swift 类型名。
- `Sources/Frog/`：应用入口、窗口、回声终端界面、命令状态与系统集成；按功能拆分 Swift 文件。`Assets/` 保存从原型导出的静态 SVG，使用 `terminal-<用途>.svg` 命名，原型图形被替换时同步替换，失去引用时删除；不保存网站图标。
- `Tests/FrogCoreTests/`：持久化和数据行为测试；临时测试数据在测试结束时删除。
- `Tests/FrogTests/`：界面状态与系统集成逻辑测试；快捷键注册使用替身，本机偏好使用隔离存储，测试后清理。
- `Resources/`：应用信息、图标和打包资源；`AppIcon.icon/` 使用共享 `../assets/frog-navigation.png` 生成满幅 PNG 图层，保留原图背景和完整构图，由系统生成圆角。`scripts/render_app_icon.swift` 只缩放原图生成 macOS 资源，`scripts/generate-icon.sh` 编译 `.icon` 与 ICNS；Windows 的 `AppIcon.ico` 由 `windows/scripts/generate-icon.ps1` 独占生成。预览只进入 `build/`。
- `scripts/`：构建、安装和独立验收工具；Shell 文件采用短横线命名，Python/Swift 工具采用下划线命名。测量数据和临时图标集只进入忽略的 `build/`，可随时清理。
- `Frog.xcodeproj/`：原生工程；`Package.swift` 提供命令行构建与测试。
- `.build/` 与 `build/` 保存编译、测试和打包产物并纳入忽略规则；其中 `build/install-backup/` 保存可恢复的旧版 ZIP，按 `README.md` 的保留与清理规则管理。清理整个 `build/` 前先检查回滚包，其余可重新生成的产物可按需清理；这些目录不存用户书签数据。

检查命令：在本目录执行 `swift test`；应用交付与安装命令见本目录 `README.md`。

界面与交互依据 `../designs/frog-echo-tui/SPEC.md`，按 1440×900 设计坐标等比绘制原生列表、命令行与缓冲区；静态 SVG 仅用于图形，文字与输入使用原生系统。数据与系统能力沿用现有实现，网站图标下载及缓存模块随切换移除，书签固定显示标题首字符与稳定的传统色底板。Windows 不在本轮重构范围。

数据修改必须经同一个串行存储模块原子提交，持久化成功后才更新已保存界面状态；外部读取失败保留数据并暂停覆盖写入。所有说明文档使用中文。

自定义命令通过 `FrogCore/CustomCommandStore` 串行原子保存到本机 `~/Library/Application Support/Frog/commands-macos.json`；不进入书签文档或备份，不随 `:cd` 切换。`--data-directory` 隔离运行使用指定目录下的同名文件。执行使用外部终端、Process 或默认浏览器，运行时参数不能重新解释为 shell 代码；真实终端只报告交接结果，不宣称命令执行成功。使用与验收见 `README.md` 的“自定义命令”。

全局快捷键通过 Carbon 注册，由应用入口持有控制器；配置仅存本机 UserDefaults，`--data-directory` 隔离运行时只保存在内存。按键录入优先于应用命令，系统文件选择器打开期间不切换启动台。

屏幕触角通过被动鼠标事件监听，由应用入口管理；几何与进入／离开状态单独测试，默认启用左下角。仅本机保存配置，隔离运行不持久化。隐藏期间不使用定时轮询，不拦截鼠标事件或修改 macOS 系统触发角。

Finder 目录快跳依据 `../plans/PLAN_FINDERJUMP.md`，默认关闭，由应用入口统一管理目录追踪、文件面板观察、浮条和条件快捷键。仅支持可靠识别的系统标准打开／保存／目录选择窗口；没有有效 Finder 目录时完全隐藏入口，并原样放行 `Control-G`。目录取最后活动 Finder 窗口当前标签页的真实目录，本次运行内缓存，关闭 Finder 窗口仍保留，虚拟位置不覆盖缓存；开关仅存本机，`--data-directory` 隔离运行仅存内存。

快跳使用辅助功能和 Finder 自动化，键盘监听／发送权限以系统预检及实际创建结果为准；不要与无需这些权限的 Carbon 启动台快捷键混淆。未开启功能不主动请求权限；关闭、权限失效或退出时停止观察与监听，取消导航并清理浮条。后台观察以事件驱动，不增加空闲定时轮询。浮条不激活启动台；导航逐步校验目标及焦点，通过辅助功能填写“前往文件夹”路径，不使用剪贴板、不自动确认外层打开／保存。真实跨应用、权限、多屏及全屏行为必须单独实测，单元测试不能代替该证据。

本机打包固定使用登录钥匙串中的 `Frog Local Code Signing` 自签名证书；首次配置运行 `scripts/setup-local-signing.sh`，后续复用同一证书和私钥。证书缺失或失效时构建失败，不自动生成新身份或退回 ad hoc。私钥只持久保存在钥匙串，临时生成文件使用受限权限并在脚本退出时清理，不进入仓库或构建产物。

旧 ad hoc 版本的系统授权可能仍绑定旧 CDHash，切换固定证书后需要重新绑定一次。安装后出现权限回退时，先核对新旧 designated requirement 和对应 TCC 日志，再处理授权重绑；不得只依据系统开关显示或签名完整性校验宣称权限已保留。重绑方法见 `README.md`，系统权限操作遵守当次用户授权。
