# 青蛙导航 原生 macOS 应用

此目录提供 macOS 14 及以上的本地书签启动台，使用 SwiftUI、AppKit 与 Foundation，不依赖网页端 API。

- `Sources/FrogCore/`：模型、数据存储、同步文件监听与可测试的纯逻辑；文件名采用 Swift 类型名。
- `Sources/FrogIcons/`：网站图标抓取、图像解码与本机缓存；不依赖书签存储。
- `Sources/Frog/`：应用入口、窗口、界面与系统集成；按功能拆分 Swift 文件。
- `Tests/FrogCoreTests/`：持久化和数据行为测试；临时测试数据在测试结束时删除。
- `Tests/FrogIconsTests/`：图标解析、请求限制与缓存测试，使用隔离临时目录。
- `Tests/FrogTests/`：界面状态与系统集成逻辑测试；快捷键注册使用替身，本机偏好使用隔离存储，测试后清理。
- `Resources/`：应用信息、图标和打包资源；`AppIcon.icon/` 使用共享 `../assets/frog-navigation.png` 生成满幅 PNG 图层，保留原图背景和完整构图，由系统生成圆角。`scripts/render_app_icon.swift` 缩放原图并生成平台资源，`scripts/generate-icon.sh` 编译 `.icon` 与 ICNS；预览只进入 `build/`。
- `scripts/`：构建、安装和独立验收工具；Shell 文件采用短横线命名，Python/Swift 工具采用下划线命名。测量数据和临时图标集只进入忽略的 `build/`，可随时清理。
- `Frog.xcodeproj/`：原生工程；`Package.swift` 提供命令行构建与测试。
- `.build/` 与 `build/` 保存编译、测试和打包产物并纳入忽略规则；其中 `build/install-backup/` 保存可恢复的旧版 ZIP，按 `README.md` 的保留与清理规则管理。清理整个 `build/` 前先检查回滚包，其余可重新生成的产物可按需清理；这些目录不存用户书签数据。

检查命令：在本目录执行 `swift test`；应用交付与安装命令见本目录 `README.md`。

功能依据：`../plans/PLAN_MACOSAPP.md`。根目录、文件夹和相关交互以 macOS Sequoia 15 的经典 Launchpad 为基准，保留 Dock，读取当前显示器壁纸并模糊，读取失败使用系统材质。仅添加／编辑书签和设置弹窗参考 `../designs/` 原型。

数据修改必须经同一个串行存储模块原子提交，持久化成功后才更新已保存界面状态；外部读取失败保留数据并暂停覆盖写入。所有说明文档使用中文。

全局快捷键通过 Carbon 注册，由应用入口持有控制器；配置仅存本机 UserDefaults，`--data-directory` 隔离运行时只保存在内存。按键录入优先于应用命令，系统文件选择器打开期间不切换启动台。

屏幕触角通过被动鼠标事件监听，由应用入口管理；几何与进入／离开状态单独测试，默认启用左下角。仅本机保存配置，隔离运行不持久化。隐藏期间不使用定时轮询，不拦截鼠标事件或修改 macOS 系统触发角。

Finder 目录快跳依据 `../plans/PLAN_FINDERJUMP.md`，默认关闭，由应用入口统一管理目录追踪、文件面板观察、浮条和条件快捷键。仅支持可靠识别的系统标准打开／保存／目录选择窗口；没有有效 Finder 目录时完全隐藏入口，并原样放行 `Control-G`。目录取最后活动 Finder 窗口当前标签页的真实目录，本次运行内缓存，关闭 Finder 窗口仍保留，虚拟位置不覆盖缓存；开关仅存本机，`--data-directory` 隔离运行仅存内存。

快跳使用辅助功能和 Finder 自动化，键盘监听／发送权限以系统预检及实际创建结果为准；不要与无需这些权限的 Carbon 启动台快捷键混淆。未开启功能不主动请求权限；关闭、权限失效或退出时停止观察与监听，取消导航并清理浮条。后台观察以事件驱动，不增加空闲定时轮询。浮条不激活启动台；导航逐步校验目标及焦点，通过辅助功能填写“前往文件夹”路径，不使用剪贴板、不自动确认外层打开／保存。真实跨应用、权限、多屏及全屏行为必须单独实测，单元测试不能代替该证据。

ad hoc 重新构建会改变代码身份，已开启的系统授权条目可能仍绑定旧 CDHash。安装后出现权限回退时，先核对新旧 designated requirement 和对应 TCC 日志，再处理授权重绑；不得只依据系统开关显示或签名完整性校验宣称权限已保留。重绑方法见 `README.md`，系统权限操作遵守当次用户授权。
