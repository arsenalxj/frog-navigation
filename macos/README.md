# 青蛙导航 macOS

> 项目内部身份已统一为 Frog，桌面显示名为“青蛙导航”。新版使用独立数据目录与备份格式，导入备份时须符合当前 `frog-bookmarks` 格式。

青蛙导航 是本机书签启动台：用 AppKit 原生绘制“回声终端”界面并管理单一覆盖窗口，静态图标取自本地 SVG 资产，不嵌入 WebView。列表、命令行、设置与帮助按 `designs/frog-echo-tui/SPEC.md` 的 1440 × 900 设计坐标等比绘制。它独立于网页端运行，书签直接保存在本地 JSON，无需部署 Cloudflare 或登录账号。

支持 macOS 14 及以上，当前交付 Apple Silicon `arm64` Release，安装位置为 `/Applications/青蛙导航.app`。应用标识固定为 `cn.arsenalxj.Frog`，使用登录钥匙串中的固定本机自签名证书 `Frog Local Code Signing`。无需付费 Apple 开发者账号；该签名用于本机使用，不等同于 Apple Developer ID 或公证。当前构建、测试和未验证边界见 [VALIDATION.md](VALIDATION.md)。

## 构建和安装

安装包含 Icon Composer／`ictool` 的完整 Xcode 26，并完成首次启动配置；本轮使用 Xcode 26.3。原生分层图标编译需要该工具链，项目没有外部 Swift 包依赖。

在仓库的 `macos/` 目录运行：

```bash
# 核心逻辑和图标模块测试；与 Release 打包分离
swift test

# 首次配置固定本机签名；系统可能要求确认钥匙串操作
./scripts/setup-local-signing.sh

# 构建可直接打开的原生 .app，校验签名和 arm64 架构
./scripts/build-release.sh

# 安装到 /Applications；安装前用 Command-Q 退出已有应用
./scripts/install.sh

# 打开应用
open /Applications/青蛙导航.app
```

交付产物为 `build/青蛙导航.app`，构建日志为 `build/build-release-日期时间.log`。Xcode 中间产物、符号文件和 Swift Package 解析产物也在 `build/` 下。`build/` 与 `.build/` 均已忽略；编译产物可以删除后重新构建，`build/install-backup/` 中的旧版回滚包应按下述保留规则清理。`build-release.sh` 只构建和打包，不自动运行测试、安装或启动应用。

`install.sh` 默认安装到 `/Applications`，也接受一个已有且可写的应用程序目录绝对路径。它会校验应用标识和签名，拒绝覆盖未知同名应用、符号链接或正在运行的目标应用。更新时先验证新包，再将旧包临时保留用于回滚；新安装签名及文件一致性检查通过后，旧包压缩成 ZIP，并实际解压验证签名和文件完整性。全部成功后才清理临时旧应用；过程中失败则恢复旧版。安装还会更新应用目录时间，并只刷新该应用的系统注册，让系统及时识别新图标。正式目录只保留 `青蛙导航.app`，旧版本不会以独立 `.app` 留在“应用程序”中供启动器索引。

`build/install-backup/` 专门保存安装回滚包和校验记录，不存用户书签。常规更新只保留一份固定的 `Frog-previous.zip` 及 `Frog-previous.json`：临时归档实际解压验证成功后，原子替换为刚被更新的旧版。`scripts/installer_archive.py` 提供归档及精确清理旧版入口。归档和校验成功后才移除原旧应用；解压校验目录在工具退出时清理。确认不再需要历史回滚时，可以手动删除对应 ZIP 及校验记录；删除整个 `build/` 前先检查或移走需要保留的回滚包。

安装完成会打印回滚包路径。需要手动恢复时，先退出 青蛙导航，将 ZIP 解压到临时目录，确认恢复包后再替换已安装应用；书签数据位置独立于应用包。安装和更新均不删除用户数据。登录项验证应使用正式安装位置，完成更新后在设置中复查系统状态。

首次运行 `setup-local-signing.sh` 会创建有效期十年的代码签名专用证书，将证书和私钥导入当前用户的登录钥匙串，并仅对代码签名设置信任。私钥只授权系统 `codesign` 工具使用；脚本不读取登录密码，系统若提示授权需由用户确认。再次运行复用现有有效身份；发现同名但失效的证书时停止，不静默更换。请妥善保留钥匙串中的证书及私钥；换机时通过钥匙串访问导出带密码的个人信息交换文件并安全转移，不放入仓库。删除、丢失或更换证书后需要重新授权。

构建脚本在打包前检查唯一且有效的证书，签名后核验实际证书指纹和应用身份，证书不可用时直接失败。Xcode 工程同样使用该证书，避免图形界面构建又退回临时签名。旧 ad hoc 版本的授权绑定构建内容，切换固定证书后需要重新授权一次：退出青蛙导航，在“系统设置 → 隐私与安全性 → 辅助功能”移除旧条目，再添加 `/Applications/青蛙导航.app` 并开启，随后重启。后续版本应保持同一证书、私钥和应用标识；授权能否跨更新延续需以新进程实际权限为准，签名完整性检查或系统开关开启都不能单独证明授权有效。

也可以直接打开 `Frog.xcodeproj`，选择工程内共享的 `Frog` scheme，运行或构建应用。Xcode 同时可能列出本地 Swift Package 派生的同名可执行 scheme；交付 `.app` 时使用工程的 scheme。命令行脚本已经指定该工程与共享 scheme。`Package.swift` 中的可执行 target 用于 Swift 命令行编译；登录项及 Launch Services 集成需要完整 `.app`。

应用图标源为仓库 `assets/frog-navigation.png`，保留用户提供的完整青蛙与白色背景。`scripts/render_app_icon.swift` 将原图缩放为 1024 × 1024 PNG 图层；`scripts/generate-icon.sh` 将 `Resources/AppIcon.icon` 编译为 `Assets.car` 和兼容旧版 macOS 的 `AppIcon.icns`。Windows 的 `windows/resources/AppIcon.ico` 只由 `windows/scripts/generate-icon.ps1` 生成，macOS 构建不写该文件。每次 Release 构建自动重建；系统渲染预览位于 `build/icon-preview/`。关于页复用应用图标。

## 使用

- 界面是 1440 × 900 设计坐标的原生“回声终端”，按屏幕可用区域等比缩放：上方单列表、下方三行日志、底部命令行与状态栏；不使用壁纸背景。
- 操作由键盘和底部 `:` 命令完成，没有弹窗或表单面板。所有修改经同一存储模块原子落盘成功后才更新界面；失败时保留未提交输入并说明原因。
- 文件夹在根目录置顶且顺序固定；`Enter`、`Tab` 或双击原地展开／折叠，子书签缩进显示并可选中打开，不再进入独立文件夹视图。展开状态保存在本机偏好，`z` 一键全部展开或折叠。搜索覆盖全部书签并标注所属文件夹。
- `/` 搜索仅在本次界面显示期间保留；收起窗口时清空搜索词并退出搜索输入，再次打开恢复未筛选列表。编辑草稿、命令输入及文件夹展开状态仍保留。
- 点击整行选中并交出键盘焦点，双击打开书签或切换文件夹展开；`Enter` 打开书签、切换文件夹展开，或提交输入。打开书签由系统默认浏览器完成，成功后收起窗口，失败时保留界面并写日志。
- `:calc` 打开计算器缓冲区：支持数字、`+ - * /`、小括号与小数，`Enter` 或 `=` 计算；`↑/↓` 按列表顺序切换历史并回填，`c` 复制当前或选中记录的结果，`:calc clear` 清空。输入法打出的中文括号自动转成英文括号，指数结果可直接回填；`Esc` 关闭后保留算式与历史。
- 书签图标固定为“标题首字符 + 由书签 ID 稳定的传统色底板”。不下载或缓存网页图标，也不提供刷新图标命令，因此无需网络即可完整显示。
- 应用作为辅助应用运行，不显示程序坞图标，也不出现在 `⌘Tab` 应用切换列表；系统 Dock 本身及其布局避让保持不变。
- `j/k` 或方向键选择，`Enter` 打开，`Esc` 逐层折叠与返回，没有分页：条目超出可视区时滚轮或 `Page Up` / `Page Down` 滚动。
- 底部按键条随当前命令步骤、输入模式与选中对象切换：编辑显示切字段与保存，删除显示确认与取消，搜索显示结果选择，整理显示排序与完成；设置、帮助、日志和计算器显示各自操作。新增／移动的返回与候选选择提示随步骤更新，执行任务时改为等待提示。输入期间隐藏状态栏中不适用的列表入口。

窗口铺满整块屏幕，层级高于菜单栏与程序坞，因此界面会同时遮住顶部菜单栏和底部程序坞；收起后两者立即恢复显示。不建立独立全屏 Space，也不读取或模糊桌面壁纸。

## 数据目录、同步与备份

设置缓冲区（`,` 或 `:set`）显示当前使用的 `bookmarks.json` 完整路径。`:cd <目录>` 切换目录；`:backup`、`:restore` 在不带参数时进入路径提示，支持 `~`、空格与真实目录/JSON 补全。

| 目标目录 | 切换结果 |
| --- | --- |
| 没有 `bookmarks.json` | 将当前已保存数据原子写入目标目录后切换 |
| 已有有效数据 | 直接使用目标数据，保留文件内容 |
| 格式无效、版本不支持或权限不足 | 提示原因，保留原目录和原有数据 |
| 选择当前目录或取消 | 保持当前状态 |

切换成功后原目录的数据保留，后续只写新目录；界面回到根目录第一页，清理旧数据对应的编辑状态。设备会记住选定目录。已经配置的目录暂时不可用时暂停写入并提示处理，保留该位置，不静默换成空数据。

主数据只包含书签、分组、ID、归属及逻辑顺序。书签图标在本地按标题首字符和书签 ID 生成，不使用图标缓存，也不产生网络请求；本机偏好包括目录、全局快捷键、屏幕触角及 Finder 目录快跳开关，登录启动状态从系统读取。Finder 最后有效目录仅在本次运行期间保留，不写入书签、备份或本机偏好。

可以把数据目录放在坚果云等同步工具管理的本地文件夹。外部有效更新会自动读取，原子替换也会被检测到；读取不原样写回。保存前检查磁盘是否变化，发生变化时载入新数据并要求重试，保留未提交表单。外部文件暂时缺失或损坏时保留已加载内容并停止覆盖写入。

青蛙导航 不负责跨设备网络传输，也不自动合并多设备同时编辑的结果。换设备时先等待同步工具完成同步，再在新设备选择包含该 `bookmarks.json` 的目录；平时轮流编辑，切换设备前等待同步完成。

- **导出备份**：`:backup [文件路径]` 创建当前完整数据的 JSON 副本，包含空文件夹，保留 ID 和排序，不改变当前目录。默认文件名为 `青蛙导航-Bookmarks-YYYYMMDD-HHmmss.json`，位于“文稿”；不能覆盖当前主数据文件。
- **恢复备份**：`:restore [文件路径]` 先完整校验，再用备份内容整体替换当前目录中的全部书签和分组，不合并或去重。相同标题／网址和原始 ID 按备份保留；有效空文件会清空数据。格式不合法或写入失败时保留旧数据。当前目录属于同步文件夹时，恢复结果会继续被同步工具传输。
- **从 Edge 导入**：`:import edge` 只读扫描本机 Edge 收藏并追加到当前数据，全局按网址精确去重；详细规则见下节。

新增、编辑、删除、搜索、整理、目录切换和备份恢复均可离线操作；任务缓冲区显示真实命令、过程与结果。书签图标固定使用本地首字符样式，不发起图标请求，也不提供刷新图标命令。实际访问网站和 Google 搜索需要系统浏览器及网络。

### 从 Microsoft Edge 导入收藏夹（仅 macOS）

在青蛙导航命令行输入：

```text
:import edge
:import edge "~/Library/Application Support/Microsoft Edge"
```

无路径时扫描稳定版默认目录。可选路径支持 Edge 数据目录、单个配置目录或 `Bookmarks` 文件；包含空格时可使用引号，不需要添加 Shell 的反斜杠转义。相对路径以当前青蛙导航数据目录为基准。设置缓冲区的数据操作区列出此命令。

- **范围**：读取 `bookmark_bar`（收藏夹栏）与 `other`（其他收藏夹），不读取 `synced`、`workspaces_v2` 等其他根节点。正常收藏夹中由 Edge 同步而来的网址仍会导入。
- **文件夹**：嵌套路径压平为 `收藏夹栏 / 开发 / 工具`，空文件夹保留，同名组合并。多个配置同时导入时加 `[Default]`、`[Profile 1]` 等目录名前缀；访客和系统配置不扫描。空配置不会阻断其他配置的导入。
- **去重**：按 URL 字符串精确匹配，在已有全部书签和本次导入内容中去重；已存在条目的标题、位置、ID 保持不变，不清理原有重复项。新条目按来源顺序追加到目标组末尾。
- **数据转换**：仅接受有效的 http/https 网址，其他协议跳过并统计；空标题使用网址，标题和压平组名超过 120 字时保留尾部并加省略号；保留有效的 Edge 创建时间，无效时间使用导入时间。
- **保存**：所有配置先解析成功，再通过现有串行存储一次原子提交。任一配置结构损坏、文件不可读、超过 32 MB 或保存失败，均不会部分导入；发生外部修改时保留外部版本并提示重试。Edge 源文件始终只读。

任务缓冲区显示新增书签、新建文件夹、重复 URL 和不支持网址的数量；未读取的其他根节点不计入跳过数量。再次导入相同来源不会重复添加。首次导入前可先用 `:backup` 保存当前数据副本。

## 全局快捷键

默认启用 `⌥Space`（Option + 空格）。青蛙导航 后台驻留时，即使正在使用其他应用，也可以展开启动台；再按一次收起。展开时使用鼠标所在显示器的当前桌面，不新建全屏 Space。正在编辑时收起会保留草稿和输入焦点；系统文件选择器打开期间不切换启动台。

在设置缓冲区用 `:set hotkey on/off` 开关、`:set hotkey record` 录入、`:set hotkey reset` 恢复默认。组合至少包含 `⌘`、`⌥`、`⌃` 之一，可叠加 `⇧`；现有应用命令保留。录入时按 `Esc` 或点击其他位置取消。录入成功即生效，旧组合释放；冲突时保留原设置，并在日志与设置中说明。若启动或恢复原绑定失败，设置中显示未生效与更换提示。

命令冲突按当前键盘布局和应用菜单检查，包括方向键、`Page Up`/`Page Down` 与搜索聚焦组合。切换输入法／键盘布局后会重新检查；若原组合与当前布局下的应用命令冲突，会暂停该绑定并在设置中说明，保留原配置。切回兼容布局会重新尝试启用，也可直接更换组合或关闭。快速收起再展开时，目标显示器变化会立即重新定位。

启动台快捷键只保存在本机，不随书签同步或备份。它使用 Carbon 系统快捷键注册接口，无需辅助功能、输入监控或屏幕录制权限；下方“Finder 目录快跳”的权限要求独立于此快捷键。`Command-Q` 完全退出后快捷键不再生效；希望登录后即可使用时，可打开下方的“登录时启动”。

## 屏幕触角

默认开启**左下角**：青蛙导航 后台驻留时，将鼠标移到屏幕左下角即可立即展开。`:set corner left-up|left-down|right-up|right-down` 选择角落，`:set corner on/off` 开关；每个显示器都使用同一选择，窗口在触碰到的显示器当前桌面打开。

触角只负责展开，鼠标停留不会反复触发或收起；移开后再触碰即可再次打开。已经展开、动画切换中、系统文件选择器打开、按住鼠标按钮或拖动时不会触发，需移开再进入。启动、启用、换角、显示器布局变化及睡眠／会话恢复时，如果鼠标已在角落，也需先移开。编辑草稿、输入焦点和选区沿用快捷键的恢复行为。

如果所选角落也配置了 macOS 系统触发角，两者可能同时触发；可更换 青蛙导航 的角落，或在系统设置中自行调整。青蛙导航 不修改系统触发角。功能使用被动鼠标事件监听，静止期间不轮询，无需辅助功能、输入监控或屏幕录制权限。监听失败会在设置中显示原因和重试入口。

触角配置仅保存在本机，不随书签同步或备份。`Command-Q` 完全退出后失效；启用触角不自动开启“登录时启动”。

## Finder 目录快跳

默认关闭。`:set finder on` 开启后，青蛙导航 后台驻留时可为其他应用调用的系统标准打开、保存和选择文件夹窗口显示目录入口。点击整条入口或按 `Control-G`，让当前文件选择窗口进入 Finder 最后活动窗口、当前标签页中的真实目录；最终打开、保存或确认选择仍由你操作。自绘文件选择器不在首版支持范围内，未可靠识别的窗口不显示入口，也不接管按键。

启用流程：

1. 执行 `:set finder on` 后，应用请求当前首项缺失权限；再执行 `:set finder authorize` 继续授权下一步，键盘监听及事件发送也按系统状态逐个请求。
2. 授权后返回 青蛙导航，应用自动检查权限；发生启动错误或授权检查超时时执行 `:set finder retry` 重新检查。辅助功能、Finder 自动化及键盘控制可用后，点击跳转生效；键盘监听未授权或启动失败时仍保留点击入口，`Control-G` 原样放行。
3. 在 Finder 中进入一个真实目录，再在其他应用打开系统文件选择窗口。目录入口显示于该窗口下方，整条入口可点击；快捷键可用时，右侧显示 `⌃G`。

没有有效目录时，入口完全隐藏，`Control-G` 保持原有行为。最后有效目录仅在本次 青蛙导航 运行中缓存，关闭 Finder 窗口仍可使用；Finder 的“最近使用”和搜索等虚拟位置不覆盖缓存。目录删除或外置盘断开后，失效目录不再作为跳转入口。退出 青蛙导航 后缓存清空。

浮条跟随文件窗口移动、缩放，不展开启动台；下方空间不足时移到上方，两处都无法容纳时隐藏浮条，但有效文件面板中的快捷键仍可使用。切换应用、关闭文件面板、关闭功能或权限失效时停止相应操作。导航经“前往文件夹”输入完整路径，不占用剪贴板；中途目标或焦点变化时中止。若 `Control-G` 与启动台快捷键冲突，可调整启动台快捷键，目录点击入口仍可使用。

功能开关仅保存在本机，不随书签同步或备份；开启此功能不自动开启登录启动。`Command-Q` 完全退出后失效。此功能需要的辅助功能、Finder 自动化及可能的键盘权限，不影响前述 Carbon 启动台快捷键无需授权的约定；浮条通过辅助功能获取窗口位置，无需屏幕录制权限。

跨应用面板识别、授权撤回、浮条首击与焦点保持、多屏及其他应用全屏场景需要真实系统验收；自动化测试只验证可替换的逻辑与状态管理。实际验证范围与已安装版本以 [VALIDATION.md](VALIDATION.md) 为准，功能方案见 [PLAN_FINDERJUMP.md](../plans/PLAN_FINDERJUMP.md)。

## 登录时启动

用 `:set login on` 开启、“:set login off” 关闭、“:set login approve” 打开系统登录项设置。应用使用 `SMAppService.mainApp` 注册、注销及读取真实状态，命令只记录系统返回的真实结果，不会伪造批准状态。登录启动应静默驻留且不显示程序坞图标，按已启用的全局快捷键、触碰已启用的屏幕触角或在 Finder 中重新打开应用才创建窗口；普通手动启动直接展开。


## 开发与隔离验收

```text
Frog.xcodeproj/          原生应用工程，共享 Frog scheme
Package.swift             本地 Swift Package 与测试入口
Sources/Frog/            应用入口、窗口、回声终端绘制、命令模型与系统集成
Sources/Frog/Assets/     从原型导出的静态 SVG 图标（terminal-*.svg）
Sources/FrogCore/        数据格式、串行原子存储、同步文件监听
Tests/FrogCoreTests/     核心逻辑和文件持久化测试
Tests/FrogTests/         终端状态、命令、整理、系统集成与保存失败行为测试
Resources/                Info.plist 与复用标记生成的应用图标
scripts/                  构建、安装和性能验收工具
build/                    可重新生成的应用、日志、测量和编译产物
```

`Sources/Frog/` 采用 Xcode 文件系统同步组，新增 Swift 文件与 `Assets/` 资源自动加入应用 target；`FrogCore` 通过本目录 Package 的产品链接，没有重复拷贝模块源码。Swift Package 构建时以 `.copy("Assets")` 打包同一批 SVG。

可以在独立临时目录运行应用，避免改变日常书签目录和本机偏好。先用 `Command-Q` 退出已有 青蛙导航，再运行：

```bash
QA_DATA="$(mktemp -d -t frog-qa)"
./build/青蛙导航.app/Contents/MacOS/Frog --data-directory "$QA_DATA"
```

`--data-directory PATH` 仅为本次进程指定数据目录，不记忆目录、全局快捷键、屏幕触角和 Finder 目录快跳开关；这些功能从各自默认值开始，仅在当前进程内保存。目录内没有数据时创建空文件。隔离数据目录不会隔离 macOS 系统授权；验收时不要请求权限或操作登录启动开关，除非该项就是本次系统集成验收目标。测试退出后可自行删除临时目录。

独立性能工具默认生成 1,000 条测试书签，启动隔离的 Release 进程，并记录 JSON 证据：

```bash
python3 -B scripts/measure_performance.py launch
# 输出本次 run.json 的绝对路径；在界面验证可操作，再按 Esc 收起
python3 -B scripts/measure_performance.py hidden --run /绝对路径/run.json
# 按 Option-Space 再次展开；完成后汇总
python3 -B scripts/measure_performance.py report --run /绝对路径/run.json
```

脚本只启动进程、读取诊断输出和系统资源，不操作界面。收起和再次展开由人工或 CUA 完成。启动前按可执行路径和应用标识检查已有 青蛙导航 实例，要求先退出正式应用；其他同名进程只记录到测量文件。`--diagnostics` 才启用 `FROG_DIAGNOSTIC` JSON 行；普通运行不输出这些计时事件。物理内存读取 `ri_phys_footprint`，不把 RSS 当成物理占用；CPU 使用 Mach 时间基准换算用户和内核时间，默认收起后再等 30 秒、采样 10 秒。指标定义与未测项会写入结果，缺失数据保留为 `null`。冷启动测新进程并包含进程创建及动态装载时间，不主动清空系统磁盘缓存；“可操作”事件表示数据载入后窗口可见且一轮主线程布局完成，不能代替真实点击检查，也不表示展开动画已经结束。
