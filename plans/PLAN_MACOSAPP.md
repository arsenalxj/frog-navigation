# 青蛙导航 macOS 本地书签启动台

## 方案概述

采用 **AppKit 原生绘制“回声终端”界面，AppKit 管理窗口**，静态图标使用从原型导出的本地 SVG 资产，不嵌入 WebView。界面与交互以 `designs/frog-echo-tui/SPEC.md` 为唯一依据：单列表、底部命令行、设置/帮助/日志/任务缓冲区，1440 × 900 设计坐标等比绘制。

首版面向本机 M4 Mac 自用，支持 macOS 14 及以上，目标是启动快、低内存、可配置登录时启动。书签和分组使用本地 JSON 保存，新增、编辑、删除、搜索、整理、备份和恢复均可离线完成。首次打开直接使用默认数据目录，用户可通过 `:cd` 改用坚果云等工具管理的同步目录。书签图标固定为标题首字符与稳定的传统色底板，不下载或缓存网页图标；用户打开书签或发起网页搜索时，由系统默认浏览器负责网页访问。

## 全屏界面与入口

- 应用以辅助应用模式运行，不显示程序坞图标，也不出现在 `⌘Tab` 列表中；系统 Dock 与菜单栏的展示设置本身不被修改。通过全局快捷键、屏幕触角或 Finder 打开应用，显示唯一窗口；快捷键与 Finder 打开时使用鼠标所在显示器，触角使用触发所在显示器，均位于当前桌面。窗口铺满整块屏幕，层级高于菜单栏与程序坞，收起后两者恢复；不创建独立的全屏 Space，收起后直接回到原来的应用。
- 界面按 1440 × 900 设计坐标等比缩放：上方单列表（行高 32，根目录 19 行、文件夹内 18 行），下方三行常驻日志（`y=664..736`），底部命令行（`y=752..792`）、状态栏（`y=796..832`）和按键提示条（`y=856`）。底色为象牙白，不读取或模糊桌面壁纸。
- 根目录先显示全部文件夹（顺序固定），再显示独立书签；“添加书签”只出现在文件夹首行，不占用根目录网格或数据。文件夹内顶部显示 `根目录 › 文件夹名` 面包屑。
- 所有编辑、设置、备份与恢复都通过底部命令行完成，没有弹窗或表单面板。设置、帮助、日志、任务输出和命令地图是占据主区域的终端缓冲区。
- `Command-,` 与裸 `,` 打开设置缓冲区；`F1` 打开可执行命令地图；`?` 打开帮助。设置缓冲区使用“设置项 / 当前值 / 命令”三列，只显示当前 `bookmarks.json`，并把数据操作单独列出。

### 首字符图标

- 书签图标固定为「标题首字符 + 传统色底板」：英文首字母大写，中文保留首字；底板颜色由书签 ID 的稳定哈希映射到八种传统色，修改标题只更新首字，底色不变。
- 该方案用于最终界面，不发起网页图标请求、不建立图标缓存，也不提供“刷新图标”命令；离线时图标照常显示。
- 文件夹、添加、搜索等图形取自 `Sources/Frog/Assets/terminal-*.svg`，解析与着色结果缓存，绘制时不重复读取资源。

## 终端交互与书签管理

### 展开、滚动与收起

- 每次展开把键盘焦点交给列表（若有未提交命令或提示流，则恢复到对应字段与选区）；不记录页码，只保留选中项与滚动位置。单击书签整行选中并交出焦点，双击或 `Enter` 打开，打开请求成功后收起窗口；失败时保留界面并提示重试。
- 列表单页滚动，不出现分页控件或圆点。滚轮、方向键、`Page Up` / `Page Down` 与 `g` / `G` 移动选择，选中项始终保持在可视区。
- 进入文件夹后列表只显示该组书签，首行为固定“添加书签”；顶部面包屑的“根目录”可点击返回。搜索结果跨文件夹平铺，并标注所属文件夹。
- Esc 按层级处理：先取消未提交输入/提示流与命令地图，再退出整理态、清空搜索、关闭文件夹，最后收起窗口。单次按键只处理当前最上层状态；未提交草稿在普通收起时保留。
- 点击空白背景或切换到其他应用时收起窗口；整理态点击空白先结束整理。系统文件选择器或已打开的菜单不会误触发收起。
- 收起后保留进程和唯一窗口，停止绘制与输入法监听。`Command-Q` 完全退出；再次通过快捷键、屏幕触角或 Finder 打开时显示现有窗口，不重复创建。

### 全局快捷键

- 默认启用 `Option-Space`，后台驻留时可从其他应用展开启动台，再按一次收起；复用同一窗口，在鼠标所在显示器的当前桌面展开。普通浏览时聚焦搜索，编辑面板存在时保留草稿与输入焦点；动画中再次按下可反转目标状态，长按只触发一次。
- 设置缓冲区通过 `:set hotkey on/off`、`:set hotkey record`、`:set hotkey reset` 提供开关、录入和恢复默认。组合至少包含 Command、Option、Control 之一，可叠加 Shift；保留应用现有命令。录入时按 Esc 或点击其他位置取消；录入期间暂停原绑定并优先接收键盘事件。
- 系统快捷键或其他应用占用时提示更换组合；只有注册成功才保存新配置，失败保留并尝试恢复原绑定，恢复失败明确显示未生效。启动注册失败只在设置中提示，可重试。
- 应用命令冲突检查使用当前键盘布局、实际菜单组合及与启动台共用的按键匹配规则，包含 Shift 和搜索聚焦。键盘布局变化后重新验证原绑定，冲突时暂停注册并保留配置，切回兼容布局重新尝试启用。录入期间保持暂停，不因布局变化提前恢复。
- 展开前重新确定目标显示器；即使收起流程尚未结束，只要目标屏幕或布局发生变化也立即定位。同屏再次展开复用当前位置。
- 使用系统 Carbon 快捷键注册接口，由应用入口管理生命周期，不申请辅助功能或输入监控权限。系统文件选择器打开期间不切换启动台；数据载入期间收到唤起请求，完成载入后再展示。
- 开关、键码与修饰键仅保存在本机 UserDefaults，不进入书签数据、同步目录或备份。`--data-directory` 隔离运行时仅保存在内存。
- `Command-Q` 完全退出后快捷键失效；可配合现有登录时启动静默驻留，快捷键设置不改变登录项状态。

### 屏幕触角

- 默认启用左下角；`:set corner left-up|left-down|right-up|right-down` 选择角落，`:set corner on/off` 开关。设置即时生效，仅在本机 UserDefaults 保存；隔离运行只保存在内存，不进入书签、同步或备份。
- 鼠标进入任意显示器所选角落的 2 × 2 逻辑点区域时立即展开，只负责打开。复用唯一窗口，在触碰的显示器当前桌面展示，沿用搜索聚焦、草稿和输入选区恢复。数据尚未载入时保留请求和屏幕 ID，载入后再显示；屏幕已断开时回退到鼠标所在屏幕。
- 每次进入只触发一次，离开 8 × 8 逻辑点区域才重新允许触发。启动台已展开或正在切换、系统文件选择器打开、鼠标按住或拖动时抑制触发；被抑制后也须移开再进入，不能在松开鼠标或收起时原地打开。
- 启动、启用、切换角落、显示器布局变化以及睡眠／会话恢复时按当前鼠标位置初始化。使用 AppKit 被动全局与本地鼠标事件监听，不定时轮询、不吞鼠标事件，无需辅助功能或输入监控权限。监听失败时设置中说明原因并提供重试。
- 不改变 macOS 系统触发角；设置中提示同角可能同时触发，可更换角落或自行调整系统设置。`Command-Q` 退出后失效，不自动改变登录项。

### 命令、搜索与编辑

- 搜索覆盖所有书签的标题和 URL，包括文件夹内部书签，结果按已有逻辑顺序平铺。每条书签只展示一次，结果中提示所属文件夹；“添加书签”不进入搜索结果。
- `/` 进入搜索，方向键移动选择，`Enter` 打开选中书签；没有匹配时 `Enter` 打开输入的网址，或交给默认浏览器进行 Google 搜索。
- `:add` 逐项输入网址、标题和位置；根目录新增默认放在根目录，文件夹内新增默认放入该文件夹，位置候选同时支持新建文件夹。`:edit [title|url]` 以当前值预填，Tab/Shift+Tab 切换字段并保留草稿，Enter 一次保存两项，Esc 全部取消。
- 标题去除首尾空白后必须非空且不超过 120 个字符；网址仅接受 http/https，输入有效域名时自动补全 https；文件夹名称非空、60 字内且不能重名。保存成功后更新列表；落盘失败时保留输入和原有数据，并在提示流与日志中说明。
- `:delete` 在命令行确认 `y/N`；`:copy` 复制链接；`:move` 通过候选移动到根目录、已有文件夹或新建文件夹，新建文件夹与移动在一次原子提交中完成。
- 文件夹支持重命名、排序和删除空文件夹；非空文件夹先移出或删除其中的书签，再删除文件夹。

### 列表整理

- `o` 进入或结束整理态；整理态在书签行显示 `[×]` 删除入口，文件夹与添加入口保持固定且不可移动。
- `Shift+↑/↓` 或 `J/K` 将当前书签移动一位，`j/k` 只改变选中项。书签不能越过置顶文件夹或添加入口，首尾边界不循环。
- 拖拽支持根目录排序、文件夹内排序、拖入文件夹和拖出到根目录；拖到另一条根目录书签中央并停留 550ms 可创建文件夹，默认名称“新建文件夹”，随后可重命名。拖动过程提供插入线、目标高亮与“停留以创建文件夹”反馈。
- 拖拽取消或落盘失败时不修改数据；成功放下后才持久化，并保持选中项与滚动位置可见。

## 数据目录、同步与备份

### 目录组织

默认数据目录只保存一个书签文件，本机偏好和静态图标不进入同步或备份：

```text
~/Library/Application Support/Frog/
└── bookmarks.json          # 书签、分组、排列顺序
```

设置中的“数据目录”决定应用正在使用哪一份书签数据。用户选择的文件夹本身就是数据目录，内部固定使用 `bookmarks.json`；可以选择普通本地文件夹，也可以选择坚果云等同步工具中的文件夹，例如预先创建的 青蛙导航 文件夹：

```text
用户选定的数据目录/
└── bookmarks.json
```

- 书签、分组、ID、归属和逻辑顺序全部放在当前数据目录的 `bookmarks.json` 中，该文件是书签数据的唯一持久化来源。
- 书签图标按标题首字符与书签 ID 在本地生成，不访问网络、不建立缓存目录，也不随数据目录移动或进入备份。
- 数据目录路径及访问所需信息、窗口展示偏好由每台设备本地保存；可序列化偏好使用 UserDefaults，登录启动状态从系统读取。这些设备相关设置不进入书签文件或备份。
- 设置变更与目录选择只保存在本机；书签文件不包含设备路径或本机偏好。

### 首次启动与切换目录

- 首次启动尚未配置数据目录时使用默认目录：主文件不存在才创建合法的空 `bookmarks.json`，已存在则读取并校验。正常读取后直接显示终端列表，不要求先选择同步目录；已有文件损坏时提示 `:restore` 恢复或 `:cd` 选择其他目录，保留原文件。
- 用户需要文件同步时执行 `:cd <目录>`，在命令行的真实路径补全中输入位置。设置缓冲区的 `file` 行显示当前完整 `bookmarks.json` 路径。
- 目录切换与数据保存使用同一串行流程；等待已提交的本地保存完成后，再处理目标目录。读取、校验和必要的读写权限检查成功后，才记录新位置并切换界面。

| 目标目录情况 | 处理规则 |
| --- | --- |
| 没有 `bookmarks.json` | 将当前已保存数据原子写入目标目录，然后切换到新目录 |
| 已有有效的 `bookmarks.json` | 直接读取并使用其中的数据，保留目标文件内容 |
| 数据损坏、格式不支持或缺少读写权限 | 说明原因，继续使用原目录和原有数据 |
| 选择了当前目录或取消选择 | 保持当前状态 |

- 切换成功后，原目录的数据保留，后续操作只写新目录；列表回到根目录，清理指向旧数据的选择、整理状态和未提交输入。
- 再次启动时使用本机记住的目录，不重复要求选择。已经配置的目录或数据文件暂时不可用时，保留该位置及已加载数据，停止写入并提示重试或重新选择；不会自动创建空文件或静默切回默认目录。

### 数据结构与保存

- 文件包含 `format: "frog-bookmarks"`、`schemaVersion: 1`、`groups` 和 `bookmarks`。`schemaVersion` 只用于识别文件格式。
- 分组保存 `id`、`name`、`order`；书签保存 `id`、`title`、`url`、`groupId`、`order`、`createdAt`。ID 使用 UUID 字符串，时间使用 Unix 毫秒时间戳。
- `groupId` 为 `null` 表示书签直接显示在根目录，其余值必须对应一个分组。根目录书签和分组共享根目录排序序列；文件夹内的书签各自使用组内排序序列。列表按顺序单页滚动，容量由窗口高度推导。
- 所有修改由同一个数据存储模块串行处理，在当前数据目录内先写临时文件，再原子替换 `bookmarks.json`，并清理临时文件。界面只将落盘成功的数据视为已保存，避免保存中断破坏上一份完整数据。
- 主数据和备份使用相同的 UTF-8 JSON 格式，字段不包含设备数据目录或本机偏好的绝对路径，便于在不同设备上直接读取。

### 配合外部同步工具与换机

- 青蛙导航 直接读写用户选择的本地目录，文件传输与同步由用户配置的外部工具完成。本机偏好保持各机独立。
- 换设备时先等待同步工具将 `bookmarks.json` 完整同步到本机，再安装并打开 青蛙导航，执行 `:cd` 选择该文件所在目录，即可直接读取书签。每台设备单独记住自己的实际目录路径，日常换机无需导入。
- 监听当前数据目录及主文件的修改、替换事件，读取并验证外部更新，成功后刷新界面；重新激活应用时也检查文件是否变化。读取外部数据不会触发原样写回，避免重复同步。
- 外部文件更新时保留未提交表单草稿；每次普通保存前核对磁盘数据是否与已读取快照一致，若已经变化，则加载最新数据并提示重试本次修改，避免直接把旧的整份数据写回。
- 文件暂时缺失或外部更新无效时，保留已加载数据并提示重试，暂停覆盖写入。此时的读取失败不解释为空数据。
- 多设备同时编辑仍可能因同步延迟产生覆盖或冲突副本；应用不自动合并不同设备的修改。使用方式以轮流编辑、切换设备前等待同步完成为准；手动恢复备份继续采用明确的整份覆盖规则。

### 另存备份

- 执行 `:backup` 时，未带路径会先进入路径提示，默认文件名为 `青蛙导航-Bookmarks-YYYYMMDD-HHmmss.json`（位于“文稿”）；`:backup <文件路径>` 直接使用给定位置。
- 将当前完整的书签、分组、ID、归属关系与排序导出为一份 JSON 副本，包括空分组；备份前完成已提交的本地保存，并检查已到达本机的外部文件更新，生成有效的一致快照。
- 备份只保存书签数据，不包含本机偏好；创建副本不改变当前使用的数据目录。保存位置应与当前主数据文件区分。
- 用户取消保存对话框时结束操作；备份成功提示保存位置，失败说明原因并允许重试。

### 恢复备份

- 执行 `:restore` 时，未带路径会先进入备份文件提示；提示明确说明“恢复后将替换当前数据目录中的全部书签和分组”。该目录由同步工具管理时，恢复结果也会由该工具继续同步。
- 文件选定后，先完整解析并验证格式版本、必要字段、文件内部 ID 唯一性、网址和分组引用。校验针对文件自身的有效性，不与当前数据进行冲突比较。
- 校验通过后直接以备份内容整体替换当前数据目录中的 `bookmarks.json`，不合并、不去重、不处理版本冲突，也不再弹出覆盖确认。备份中的 ID、同名书签、相同 URL 和排序均按原样保留；合法的空数据文件会清空当前书签和分组。
- 恢复通过同一数据存储模块原子提交；数据目录位置保持不变。成功后刷新列表，清空搜索、选择、整理状态和未提交输入，回到根目录，并在任务缓冲区与日志中报告书签与分组数量。
- 文件损坏、格式版本不支持、校验失败或写入失败时，保持原有数据完整并提示具体原因；用户取消文件选择时不改变数据。

## 原生工程与系统集成

- 在当前仓库 `macos/` 下新增独立的原生 macOS 项目，包含 Xcode 工程、Swift 源码、测试和中文说明；先建立目录规范，构建产物单独存放并加入忽略规则。Swift Package 提供独立 `FrogCore` 数据模块、`Frog` 应用入口和核心测试。
- AppKit 使用 `NSWindowController` 管理可获得键盘焦点的无边框覆盖窗口，以自定义 `NSView` 原生绘制终端界面并承载真实 `NSTextField` 命令行输入（中文输入法、选择、粘贴、撤销）。按当前显示器可用区域布局，并处理显示器切换、拔插和分辨率变化。
- 窗口不修改系统 presentation options，保留用户菜单栏与 Dock 设置；界面只按可用区域等比缩放，不读取或模糊桌面壁纸，无需屏幕录制权限。
- 绘制只处理可视行，静态 SVG 图标解析与着色结果缓存；隐藏时停止刷新与输入法监听，不保留定时轮询。尊重系统的减少动态效果与降低透明度设置。
- 登录时启动默认关闭，通过 `:set login on/off` 控制，`:set login approve` 打开系统登录项设置。应用使用 `SMAppService.mainApp` 注册、注销和读取真实状态；需要系统批准时只记录真实状态，不假定批准成功。
- 登录 macOS 后静默驻留且不显示程序坞图标，首次按全局快捷键、触碰已启用的屏幕触角或通过 Finder 打开才创建主界面；隐藏期间没有轮询和持续动画。
- 第一阶段先验证本机 ad hoc 签名的 `.app` 是否能注册登录项；若系统拒绝注册，提供系统登录项的手动配置入口，并明确显示限制。
- 交付 Apple Silicon Release `.app`，安装到“应用程序”，提供快捷键／屏幕触角入口、移除旧程序坞固定快捷方式、设置登录启动、选择同步数据目录及备份恢复的说明。

## 验证与验收

- **首次启动与离线操作：** 从首次启动开始断网，验证自动建立默认目录并直接进入终端列表，随后验证新增、编辑、删除、搜索、创建文件夹、拖拽整理、关闭重开和备份恢复；图标由标题首字符本地生成，断网不影响显示。
- **首字符图标：** 验证中英文首字、空白标题回退、标题修改后首字更新且底色由 ID 保持稳定；确认没有图标网络请求、没有图标缓存目录，`help` 与命令目录不含刷新图标命令。
- **终端交互：** 展开与收起、文件夹进出与面包屑、Esc 分层处理、单页滚动与选中可见、整理排序、拖拽创建文件夹及失败回滚、设置/帮助/日志/任务/命令地图缓冲区。
- **命令一致性：** `:add`、`:edit`、`:mkdir`、`:rename`、`:move`、`:delete`、`:group`、`:find`、`:backup`、`:restore`、`:cd`、`:set` 均有真实落盘结果；设置缓冲区单字符不触发操作，`Esc` 逐层返回；命令地图 Enter 执行真实命令。
- **本地持久化：** 重启后书签、文件夹归属及顺序保持一致；写入失败或中断后上一份数据仍可读取；窗口尺寸变化只调整布局与滚动容量，不改变逻辑排序。
- **目录切换：** 空目录复制当前数据，已有有效数据的目录直接读取；格式错误、权限不足、取消输入均保留原目录状态。切换成功后只写新目录，原文件仍在；重启记住目录，目录或文件不可用时不生成空数据。
- **同步与换机：** 设备 B 执行 `:cd` 选择已同步的数据目录即可读取与设备 A 一致的书签、分组、ID、归属和顺序；两台设备的本机偏好各自独立。外部原子替换文件后界面刷新，读取不触发写回，无效更新保持当前可用状态；保存遇到已到达的外部修改时保留草稿并提示重试。
- **备份与恢复：** 备份不改变数据目录，文件不包含图标或设备路径；恢复仅替换当前目录中的完整数据。同名或相同 URL 按备份保留，空备份可清空，损坏文件和无效引用不得破坏旧数据；有效恢复结果可由外部工具同步到另一台设备。
- **窗口与系统集成：** 手动启动、静默驻留和反复展开均不显示应用程序坞图标；通过快捷键、屏幕触角或 Finder 反复唤起只保留一个窗口，多显示器及其他应用全屏时定位正确；系统菜单栏和 Dock 保持用户原有设置，系统文件选择器不会造成误收起或阻塞输入。
- **全局快捷键：** 自动测试默认值、持久化与隔离、开关、录入取消、冲突回退、长按去重、启动加载和切换决策；在完整 Release `.app` 中验证从其他应用唤起／收起、隐藏后唤起、快速连按、草稿与焦点保留、修改组合、静默启动和退出释放。系统权限提示、多显示器／其他应用全屏与真实登录分别记录实际覆盖结果。
- **屏幕触角：** 自动测试四角／边界／负坐标／多屏目标、进入去重与离开阈值、拖动及窗口保护、初始化与休眠恢复、监听生命周期、配置持久化及隔离和加载挂起。在完整 Release `.app` 中检查设置布局、后台首次触发、连续停留、换角及关闭、文件选择器与草稿恢复；物理多显示器、其他应用全屏、实际鼠标触碰、睡眠和真实登录分别记录结果。确认静止期间没有轮询及新增权限请求。
- **登录启动：** 在实际安装的 `.app` 中验证设置开关和系统状态；真实登录后确认静默启动，应用更新后复查注册状态。重新登录由用户在合适时机完成。
- **性能目标：** 本机 Release、1,000 条本地书签条件下，冷启动到可操作不超过 1 秒，再次展开不超过 150 毫秒；收起 30 秒后物理内存目标不超过 100 MB，空闲 CPU 平均不超过 1%。这些是实施后的实测验收目标。
