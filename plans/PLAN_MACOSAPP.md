# 青蛙导航 macOS 本地书签启动台

## 方案概述

采用 **SwiftUI 绘制界面，AppKit 管理程序坞和全屏窗口**，完全使用系统原生框架。以 **macOS Sequoia 15 的经典 Launchpad** 为根目录、文件夹及动画交互基准，尽量还原全屏图标网格、横向分页、文件夹和拖拽整理。`designs/` 原型仅用于添加／编辑书签弹窗及设置弹窗。

首版面向本机 M4 Mac 自用，支持 macOS 14 及以上，目标是启动快、低内存、可配置登录时启动。书签和分组使用本地 JSON 保存，新增、编辑、删除、搜索、整理、备份和恢复均可离线完成。首次打开直接使用默认数据目录，用户可在设置中改用坚果云等工具管理的同步目录。网站图标通过网络异步获取并缓存在本机，核心书签操作不依赖图标请求；用户打开书签或发起网页搜索时，由系统默认浏览器负责网页访问。

## 全屏界面与入口

- 点击程序坞图标，在鼠标所在显示器的当前桌面显示唯一的全屏启动台。界面覆盖整块屏幕，采用无边框窗口；不创建独立的全屏 Space，收起后直接回到原来的应用。
- 顶部居中放置搜索框，设置齿轮按钮放在搜索框右侧并垂直居中。主体为均匀排列的图标和名称，底部显示分页圆点。背景读取当前显示器的桌面壁纸并模糊，读取失败回退系统材质，无需截屏。使用系统字体，展开收起、跟手翻页和回弹、文件夹展开、拖拽让位及整理抖动参考经典 Launchpad；图标尺寸、标题基线、间距与点击区域统一，适配屏幕尺寸和浅色/深色外观。
- 根目录显示独立书签和文件夹；文件夹是分组的界面表现，图标内展示组内书签的缩略预览。文件夹只包含书签，采用单层结构。
- 根目录的“添加书签”入口位于顶部设置按钮右侧，使用加号按钮，在根目录、搜索结果和空态下均可用，打开表单时默认选择根目录。根目录网格只排列书签和文件夹，添加入口不占用网格单元、不预留空位，也不参与分页、拖拽排序或书签数据。
- 文件夹内保留“添加书签”功能图标，使用加号，并与普通书签采用相同的图标尺寸和名称排版；空文件夹也提供该入口。点击后打开同一表单，自动选中当前文件夹。该图标位置固定，不参与拖拽排序，也不属于书签数据。
- 搜索框右侧的“设置”是独立按钮，不占用书签网格单元，也不参与书签排序、分页和导出。点击后打开启动台内的原生设置面板，集中提供数据目录、另存备份、恢复备份、登录时启动及应用信息；`Command-,` 打开同一设置面板。

### 网站图标

- 优先使用已经缓存的站点图标。缓存缺失时，先显示根据标题或域名首字符生成的本地图标，再异步抓取网站图标；抓取和解码不阻塞首屏、搜索或书签保存。
- 通过原生网络请求读取书签网页，解析 HTML 中的 `rel="icon"`、`rel="shortcut icon"` 和 `rel="apple-touch-icon"`，选择可解码且尺寸合适的图标。相对地址按网页最终地址和有效的 HTML base 地址解析；没有可用声明时尝试站点根目录的 `/favicon.ico`。
- 图标获取成功后，按实际显示尺寸解码并保存到本机 `~/Library/Caches/Frog/` 下的图标缓存，后续打开直接复用。缓存记录资源来源和对应网页地址，书签修改网址后重新匹配图标；书签菜单提供“刷新图标”。缓存位置独立于数据目录，切换数据目录时继续复用有效缓存。
- 获取不到图标且没有有效缓存时，使用统一圆角底板和标题或域名首字符。已有缓存的刷新失败时继续显示旧图标，避免把可用图标替换成占位图。
- 请求只允许 http/https，并设置超时、重定向次数、响应体和图像解码尺寸限制；失败后不持续轮询。文件夹预览由组内图标组合，添加书签和设置使用系统图标。

## Launchpad 交互与书签管理

### 展开、翻页与收起

- 每次展开自动聚焦搜索，恢复本机记录的根目录页码。单击书签即交给默认浏览器打开，打开请求成功后收起启动台；失败时保留界面并提示重试。
- 通过触控板左右滑动、鼠标横向滚动或点击分页圆点切换页面；键盘 `Page Up` / `Page Down` 翻页。根据当前屏幕重新计算每页容量，保留图标的逻辑顺序。
- 点击文件夹，在当前全屏界面内展开文件夹面板，背景图标弱化；遮罩与背景弱化在打开、关闭时立即切换，仅文件夹标题及面板使用展开、收起动画。文件夹内容较多时同样支持横向分页。点击文件夹外的空白区域返回根目录。
- Esc 按层级处理：先关闭当前设置或编辑面板，再退出整理态、清空搜索、关闭文件夹，最后收起启动台。单次按键只处理当前最上层状态；新增、编辑表单未提交的草稿在普通收起时保留。
- 根目录浏览态点击空白背景，或切换到其他应用时收起启动台；整理态点击空白先结束整理。应用内菜单、设置和系统文件选择器不会误触发收起。
- 收起后保留进程和唯一窗口，停止不可见内容的动画与刷新。`Command-Q` 完全退出；再次点击程序坞图标显示现有窗口，不重复创建。

### 全局快捷键

- 默认启用 `Option-Space`，后台驻留时可从其他应用展开启动台，再按一次收起；复用同一窗口，在鼠标所在显示器的当前桌面展开。普通浏览时聚焦搜索，编辑面板存在时保留草稿与输入焦点；动画中再次按下可反转目标状态，长按只触发一次。
- “设置 → 通用 → 全局快捷键”提供开关、点击录入和恢复默认。组合至少包含 Command、Option、Control 之一，可叠加 Shift；保留应用现有命令。按 Esc、点击其他位置、离开通用设置或切换应用取消录入；录入期间暂停原绑定并优先接收键盘事件。
- 系统快捷键或其他应用占用时提示更换组合；只有注册成功才保存新配置，失败保留并尝试恢复原绑定，恢复失败明确显示未生效。启动注册失败只在设置中提示，可重试。
- 应用命令冲突检查使用当前键盘布局、实际菜单组合及与启动台共用的按键匹配规则，包含 Shift 和搜索聚焦。键盘布局变化后重新验证原绑定，冲突时暂停注册并保留配置，切回兼容布局重新尝试启用。录入期间保持暂停，不因布局变化提前恢复。
- 展开前重新确定目标显示器；即使收起动画尚未结束，只要目标屏幕或布局发生变化也立即定位。同屏动画反转复用当前位置，完全收起后再打开会刷新壁纸和布局。
- 使用系统 Carbon 快捷键注册接口，由应用入口管理生命周期，不申请辅助功能或输入监控权限。系统文件选择器打开期间不切换启动台；数据载入期间收到唤起请求，完成载入后再展示。
- 开关、键码与修饰键仅保存在本机 UserDefaults，不进入书签数据、同步目录或备份。`--data-directory` 隔离运行时仅保存在内存。
- `Command-Q` 完全退出后快捷键失效；可配合现有登录时启动静默驻留，快捷键设置不改变登录项状态。

### 屏幕触角

- 默认启用左下角；“设置 → 通用 → 屏幕触角”可关闭，并在左上、左下、右上、右下中选择一个角落。设置即时生效，仅在本机 UserDefaults 保存；隔离运行只保存在内存，不进入书签、同步或备份。
- 鼠标进入任意显示器所选角落的 2 × 2 逻辑点区域时立即展开，只负责打开。复用唯一窗口，在触碰的显示器当前桌面展示，沿用搜索聚焦、草稿和输入选区恢复。数据尚未载入时保留请求和屏幕 ID，载入后再显示；屏幕已断开时回退到鼠标所在屏幕。
- 每次进入只触发一次，离开 8 × 8 逻辑点区域才重新允许触发。启动台已展开或正在切换、系统文件选择器打开、鼠标按住或拖动时抑制触发；被抑制后也须移开再进入，不能在松开鼠标或收起时原地打开。
- 启动、启用、切换角落、显示器布局变化以及睡眠／会话恢复时按当前鼠标位置初始化。使用 AppKit 被动全局与本地鼠标事件监听，不定时轮询、不吞鼠标事件，无需辅助功能或输入监控权限。监听失败时设置中说明原因并提供重试。
- 不改变 macOS 系统触发角；设置中提示同角可能同时触发，可更换角落或自行调整系统设置。`Command-Q` 退出后失效，不自动改变登录项。

### 搜索、新增与编辑

- 搜索覆盖所有书签的标题和 URL，包括文件夹内部书签，结果按已有逻辑顺序平铺。每条书签只展示一次，结果中提示所属文件夹；功能图标不计入匹配结果。
- 方向键移动选择，Enter 打开首个或选中的书签；没有匹配时打开输入的网址，或交给默认浏览器进行 Google 搜索。
- 点击“添加书签”打开原生表单，填写网址、标题和所属位置。根目录新增默认放在根目录；文件夹内新增默认放入该文件夹，位置选择器同时支持新建文件夹。位置选择使用与输入框同宽高的整行菜单，左侧显示当前文字、右侧显示下拉箭头，可切换根目录、已有文件夹和新建文件夹。
- 标题去除首尾空白后必须非空且不超过 120 个字符；网址仅接受 http/https，输入有效域名时自动补全 https。保存成功后关闭表单并显示新图标，写入失败时保留输入和原有数据。
- 书签右键菜单提供打开、复制链接、编辑、刷新图标、移动到文件夹/根目录和删除。删除书签需要确认；复制链接只复制 URL。
- 文件夹支持重命名、排序和删除空文件夹；非空文件夹先移出或删除其中的书签，再删除文件夹。

### 拖拽与整理

- 长按图标进入整理态，显示轻微抖动与删除入口；结束整理立即停止抖动。根目录和文件夹首行的删除按钮完整显示圆形与阴影，横向分页仍保持相邻页内容不提前外露。功能图标保持固定且不显示删除入口。
- 拖拽支持根目录排序、文件夹内排序、拖入文件夹、拖出到根目录和跨页移动。拖到屏幕左右边缘并停留时翻页，拖动过程提供明确的目标和插入位置反馈。
- 将一个书签拖到另一个书签上并停留，显示创建文件夹预览；松开后将两条书签放入新文件夹，默认名称为“新建文件夹”，并进入名称编辑。拖入已有文件夹时移动书签归属。
- 文件夹本身参与根目录排序；文件夹之间的拖拽仅调整顺序。拖拽取消时恢复原位置，只有成功放下后才持久化数据；落盘失败时回滚本次整理并提示原因。

## 数据目录、同步与备份

### 目录组织

默认数据目录与图标缓存分开存放：

```text
~/Library/Application Support/Frog/
└── bookmarks.json          # 书签、分组、排列顺序

~/Library/Caches/Frog/
├── icons/
│   └── <网址哈希>.png       # 下载并规范化的网站图标
└── icons-index.json        # 图标来源和缓存记录
```

设置中的“数据目录”决定应用正在使用哪一份书签数据。用户选择的文件夹本身就是数据目录，内部固定使用 `bookmarks.json`；可以选择普通本地文件夹，也可以选择坚果云等同步工具中的文件夹，例如预先创建的 青蛙导航 文件夹：

```text
用户选定的数据目录/
└── bookmarks.json
```

- 书签、分组、ID、归属和逻辑顺序全部放在当前数据目录的 `bookmarks.json` 中，该文件是书签数据的唯一持久化来源。
- 图标和缓存索引固定保存在本机缓存目录，不随数据目录移动或参与数据同步，也不写入备份文件。缓存可以删除或重建，清理缓存不影响书签和分组。
- 数据目录路径及访问所需信息、当前页码、窗口展示偏好由每台设备本地保存；可序列化偏好使用 UserDefaults，登录启动状态从系统读取。这些设备相关设置不进入书签文件或备份。
- 图标缓存使用网址哈希定位资源，索引中的文件引用采用缓存内相对位置；换设备后按书签网址重新获取图标，断网时使用本地首字符图标。

### 首次启动与切换目录

- 首次启动尚未配置数据目录时使用默认目录：主文件不存在才创建合法的空 `bookmarks.json`，已存在则读取并校验。正常读取后直接显示启动台及添加书签入口，不要求先选择同步目录；已有文件损坏时提示恢复或选择其他目录，保留原文件。
- 用户需要文件同步时，进入“设置 → 数据目录 → 选择目录”，通过系统目录选择器指定位置。设置中显示当前完整路径，并提供在 Finder 中打开该目录的操作。
- 目录切换与数据保存使用同一串行流程；等待已提交的本地保存完成后，再处理目标目录。读取、校验和必要的读写权限检查成功后，才记录新位置并切换界面。

| 目标目录情况 | 处理规则 |
| --- | --- |
| 没有 `bookmarks.json` | 将当前已保存数据原子写入目标目录，然后切换到新目录 |
| 已有有效的 `bookmarks.json` | 直接读取并使用其中的数据，保留目标文件内容 |
| 数据损坏、格式不支持或缺少读写权限 | 说明原因，继续使用原目录和原有数据 |
| 选择了当前目录或取消选择 | 保持当前状态 |

- 切换成功后，原目录的数据保留，后续操作只写新目录；刷新网格并回到根目录第一页，清理指向旧数据的选择、整理状态和编辑草稿。图标缓存不搬迁。
- 再次启动时使用本机记住的目录，不重复要求选择。已经配置的目录或数据文件暂时不可用时，保留该位置及已加载数据，停止写入并提示重试或重新选择；不会自动创建空文件或静默切回默认目录。

### 数据结构与保存

- 文件包含 `format: "frog-bookmarks"`、`schemaVersion: 1`、`groups` 和 `bookmarks`。`schemaVersion` 只用于识别文件格式。
- 分组保存 `id`、`name`、`order`；书签保存 `id`、`title`、`url`、`groupId`、`order`、`createdAt`。ID 使用 UUID 字符串，时间使用 Unix 毫秒时间戳。
- `groupId` 为 `null` 表示书签直接显示在根目录，其余值必须对应一个分组。根目录书签和分组共享根目录排序序列；文件夹内的书签各自使用组内排序序列。分页由顺序和屏幕容量推导。
- 所有修改由同一个数据存储模块串行处理，在当前数据目录内先写临时文件，再原子替换 `bookmarks.json`，并清理临时文件。界面只将落盘成功的数据视为已保存，避免保存中断破坏上一份完整数据。
- 主数据和备份使用相同的 UTF-8 JSON 格式，字段不包含设备数据目录或图标缓存的绝对路径，便于在不同设备上直接读取。

### 配合外部同步工具与换机

- 青蛙导航 直接读写用户选择的本地目录，文件传输与同步由用户配置的外部工具完成。图标缓存和本机偏好保持各机独立。
- 换设备时先等待同步工具将 `bookmarks.json` 完整同步到本机，再安装并打开 青蛙导航，在设置中选择该文件所在目录，即可直接读取书签。每台设备单独记住自己的实际目录路径，日常换机无需导入。
- 监听当前数据目录及主文件的修改、替换事件，读取并验证外部更新，成功后刷新界面；重新激活应用时也检查文件是否变化。读取外部数据不会触发原样写回，避免重复同步。
- 外部文件更新时保留未提交表单草稿；每次普通保存前核对磁盘数据是否与已读取快照一致，若已经变化，则加载最新数据并提示重试本次修改，避免直接把旧的整份数据写回。
- 文件暂时缺失或外部更新无效时，保留已加载数据并提示重试，暂停覆盖写入。此时的读取失败不解释为空数据。
- 多设备同时编辑仍可能因同步延迟产生覆盖或冲突副本；应用不自动合并不同设备的修改。使用方式以轮流编辑、切换设备前等待同步完成为准；手动恢复备份继续采用明确的整份覆盖规则。

### 另存备份

- 在“设置”中点击“另存备份”，使用系统保存对话框选择位置，默认文件名为 `青蛙导航-Bookmarks-YYYYMMDD-HHmmss.json`。
- 将当前完整的书签、分组、ID、归属关系与排序导出为一份 JSON 副本，包括空分组；备份前完成已提交的本地保存，并检查已到达本机的外部文件更新，生成有效的一致快照。
- 备份只保存书签数据，不包含图标缓存和设备偏好；创建副本不改变当前使用的数据目录。保存位置应与当前主数据文件区分。
- 用户取消保存对话框时结束操作；备份成功提示保存位置，失败说明原因并允许重试。

### 恢复备份

- 在“设置”中点击“恢复备份”，使用系统文件选择器选择备份 JSON。入口旁明确说明“恢复后将替换当前数据目录中的全部书签和分组”；该目录由同步工具管理时，恢复结果也会由该工具继续同步。
- 文件选定后，先完整解析并验证格式版本、必要字段、文件内部 ID 唯一性、网址和分组引用。校验针对文件自身的有效性，不与当前数据进行冲突比较。
- 校验通过后直接以备份内容整体替换当前数据目录中的 `bookmarks.json`，不合并、不去重、不处理版本冲突，也不再弹出覆盖确认。备份中的 ID、同名书签、相同 URL 和排序均按原样保留；合法的空数据文件会清空当前书签和分组。
- 恢复通过同一数据存储模块原子提交；数据目录位置保持不变。成功后刷新网格，清空搜索、选择、整理状态和编辑草稿，回到根目录第一页，并提示恢复的书签与分组数量。
- 文件损坏、格式版本不支持、校验失败或写入失败时，保持原有数据完整并提示具体原因；用户取消文件选择时不改变数据。

## 原生工程与系统集成

- 在当前仓库 `macos/` 下新增独立的原生 macOS 项目，包含 Xcode 工程、Swift 源码、测试和中文说明；先建立目录规范，构建产物单独存放并加入忽略规则。Swift Package 提供独立 `FrogCore` 数据模块、`Frog` 应用入口和核心测试。
- AppKit 使用 `NSWindowController` 管理可获得键盘焦点的无边框全屏覆盖窗口，`NSHostingController` 承载 SwiftUI；按当前显示器尺寸布局，并处理显示器切换、拔插和分辨率变化。
- 展开期间使用系统 presentation options 自动隐藏菜单栏并保留 Dock，布局为 Dock 留出空间；收起、退出或启动异常恢复时还原展示状态。读取当前显示器桌面壁纸并模糊，读取失败回退系统背景材质，无需截取桌面或申请屏幕录制权限。
- 使用 SwiftUI 按页构建图标网格，按实际显示尺寸解码网站图标或生成首字符图标，并限制内存缓存；只保留当前页和必要的相邻页视图。尊重系统的减少动态效果与降低透明度设置。
- 设置中提供“登录时启动”，默认关闭。通过 `SMAppService.mainApp` 注册、注销和读取真实状态；需要系统批准时显示进入登录项设置的入口。
- 登录 macOS 后静默驻留，首次点击 Dock、按全局快捷键或触碰已启用的屏幕触角才创建主界面；隐藏期间没有轮询和持续动画。
- 第一阶段先验证本机 ad hoc 签名的 `.app` 是否能注册登录项；若系统拒绝注册，提供系统登录项的手动配置入口，并明确显示限制。
- 交付 Apple Silicon Release `.app`，安装到“应用程序”，提供保留在程序坞、设置登录启动、选择同步数据目录及备份恢复的说明。

## 验证与验收

- **首次启动与离线操作：** 从首次启动开始断网，验证自动建立默认目录并直接进入启动台，随后验证新增、编辑、删除、搜索、创建文件夹、拖拽、关闭重开和备份恢复；已有图标缓存正常显示，缺失时显示本地首字符图标，抓取失败不影响使用。
- **网站图标：** 验证网页图标声明、相对路径、重定向、根目录图标回退、本地缓存复用、手动刷新和网址修改后的重新获取；超时、损坏图片、超限资源及无网络时回退正确，启动和保存不等待网络。
- **Launchpad 交互：** 全屏展开与收起、横向分页、文件夹打开与关闭、Esc 分层处理、长按整理、跨页拖拽、拖拽创建文件夹及失败回滚。
- **入口一致性：** 顶部设置按钮位于搜索框右侧，加号按钮紧接设置右侧；根目录、搜索结果和空态均可通过顶部加号打开添加表单，默认位置为根目录。根目录网格不包含添加单元或为其保留空位，分页容量全部用于书签和文件夹。文件夹内及空文件夹保留添加功能图标，打开同一表单并默认选中当前文件夹。设置和添加入口均不能被拖走、删除或写入导出文件。
- **本地持久化：** 重启后书签、文件夹归属及顺序保持一致；写入失败或中断后上一份数据仍可读取；屏幕变化只调整分页，不改变逻辑排序。
- **目录切换：** 空目录复制当前数据，已有有效数据的目录直接读取；格式错误、权限不足、取消选择均保留原目录状态。切换成功后只写新目录，原文件仍在，图标缓存位置不变；重启记住目录，目录或文件不可用时不生成空数据。
- **同步与换机：** 设备 B 选择已同步的数据目录即可读取与设备 A 一致的书签、分组、ID、归属和顺序；两台设备的图标缓存和偏好各自独立。外部原子替换文件后界面刷新，读取不触发写回，无效更新保持当前可用状态；保存遇到已到达的外部修改时保留草稿并提示重试。
- **备份与恢复：** 备份不改变数据目录，文件不包含图标或设备路径；恢复仅替换当前目录中的完整数据。同名或相同 URL 按备份保留，空备份可清空，损坏文件和无效引用不得破坏旧数据；有效恢复结果可由外部工具同步到另一台设备。
- **窗口与系统集成：** 反复点击 Dock 只保留一个窗口，多显示器及其他应用全屏时定位正确；收起后菜单栏和程序坞恢复，系统文件选择器不会造成误收起或阻塞输入。
- **全局快捷键：** 自动测试默认值、持久化与隔离、开关、录入取消、冲突回退、长按去重、启动加载和切换决策；在完整 Release `.app` 中验证从其他应用唤起／收起、隐藏后唤起、快速连按、草稿与焦点保留、修改组合、静默启动和退出释放。系统权限提示、多显示器／其他应用全屏与真实登录分别记录实际覆盖结果。
- **屏幕触角：** 自动测试四角／边界／负坐标／多屏目标、进入去重与离开阈值、拖动及窗口保护、初始化与休眠恢复、监听生命周期、配置持久化及隔离和加载挂起。在完整 Release `.app` 中检查设置布局、后台首次触发、连续停留、换角及关闭、文件选择器与草稿恢复；物理多显示器、其他应用全屏、实际鼠标触碰、睡眠和真实登录分别记录结果。确认静止期间没有轮询及新增权限请求。
- **登录启动：** 在实际安装的 `.app` 中验证设置开关和系统状态；真实登录后确认静默启动，应用更新后复查注册状态。重新登录由用户在合适时机完成。
- **性能目标：** 本机 Release、1,000 条本地书签条件下，冷启动到可操作不超过 1 秒，再次展开不超过 150 毫秒；收起 30 秒后物理内存目标不超过 100 MB，空闲 CPU 平均不超过 1%。这些是实施后的实测验收目标。
