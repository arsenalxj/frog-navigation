# macOS 键盘操作统一整改方案

状态：已按用户确认实施并完成定向测试及原生输入验收（2026-11-17）。范围：macOS；Windows、网页原型和正式用户数据不变。当前使用说明见 `macos/README.md`，验证证据与边界见 `macos/VALIDATION.md`。

## 1. 推荐结论

保留回声终端的列表快捷操作与 `:` 命令入口，不改造成另一套 Vim，也不全面换绑。统一三件事：焦点归属、相同操作的键位、退出与破坏性操作的边界。

基本规则：

- 文本焦点接收文字，列表焦点接收单字母操作；方向键移动选择不隐式夺走文本焦点。
- `Tab / Shift+Tab` 切换焦点或字段。仅在独立命令输入中保留 Tab 补全；不再用 Tab 展开文件夹、进入子目录或轮换候选。
- `Enter` 执行当前焦点明确展示的主动作；选择候选不等于提交整个编辑，浏览历史不等于计算。
- `Esc` 只取消最内层临时交互或返回，不折叠文件夹、不终止后台任务。
- 复制到剪贴板与创建配置副本分开，保存与切换字段分开。
- 所有操作只作用于可见的当前上下文；不操作被缓冲区遮住的书签选择。

不推荐全面移除终端单字母键：`a/e/m/o/z` 在列表焦点下没有文字输入歧义，全部换绑只会增加迁移成本。保留 `j/k`、`g/G` 作为列表导航别名，但按键条以方向键为主。

## 3. 通用键盘契约

### 3.1 焦点与文本编辑

- 中文组字优先于应用快捷键。Enter、Esc、方向键、Tab 先交给正在组字的输入法。
- 文本编辑保留 ⌘A/C/X/V/Z、⇧⌘Z、⌥←→、⌘←→、Shift 选区、Backspace/Delete 的系统语义。
- 进入预填字段光标位于末尾，不自动全选；切换焦点保留草稿，不因导航覆盖文字。
- `Shift+↑↓` 仅在主列表整理模式下排序；有文本焦点时仍用于原生文本操作。
- 列表单字母键严格匹配修饰键，不把 ⌘/⌥/⌃ 组合或输入法文字当成裸键动作。

### 3.2 核心按键

| 按键 | 整改后契约 |
| --- | --- |
| ↑↓ | 选择列表/候选；搜索输入中选择结果但保留输入焦点 |
| Page Up / Down | 列表按可见容量移动；日志/执行输出按一屏滚动，不能当成一行 |
| Tab / Shift+Tab | 正向/反向切换焦点、字段；独立命令输入中补全/反向补全 |
| Enter | 打开/运行选中项、计算、采纳候选、保存编辑；由当前可见焦点决定 |
| Esc | 取消当前临时交互，再返回上一层；主界面无临时状态时收起 |
| ⌘C | 原生文本选择优先；列表复制当前对象的明确文本；calc 无文字选区时复制结果 |
| ⌘D | 仅命令列表：创建所选命令的副本草稿，不立即保存 |
| ⌘N / a | 主列表新建书签，命令列表新建命令；calc 不跨页新增书签；a 仅列表焦点生效 |
| e | 编辑当前项；文件夹也用 e 重命名，移除 r 键位别名 |
| Shift+D | 主列表/命令列表请求删除；保留显式确认 |
| : | 列表与 calc 打开命令输入；其他文本字段中仍是文字，不抢占路径/网址 |
| ⌘, | 打开设置；有未结束编辑时不覆盖草稿 |

`⌘C` 的对象定义：书签为完整网址；命令列表为 `:<命令名>` 调用文本；calc 历史焦点为选中记录结果，算式焦点无文字选区时为当前算式结果。无有效对象或无可计算结果时不改写剪贴板，并反馈原因。其他文本输入无选区时不回退复制底层对象。

移除 c/C 复制别名、命令 c 创建副本、文件夹 Tab 展开、calc `=` 计算别名。保留已有 `a` 与 ⌘N 双入口是为了维持终端操作与 macOS 菜单的一致性，不再继续增加同义键。

全局唤起、⌘H、⌘Q 与 Finder 快跳 ⌃G 保持现有职责。新增绑定同步纳入全局快捷键冲突检查，按实际修饰键组合保留，不扩大占用范围。

## 4. 主界面

### 搜索

主界面与命令管理使用同一规则：

1. 列表按 `/` 进入搜索；已有筛选时恢复该查询。
2. ↑↓ 改变结果选择，但继续打字仍修改搜索词。
3. Tab 有结果时进入列表操作；Shift+Tab 从结果列表返回搜索输入。空结果不转移到无效选择。
4. Enter 直接执行选中结果：书签打开，命令运行。命令搜索不再需要“Enter 结束输入、再 Enter 运行”。
5. Esc 清空并退出搜索；从筛选结果列表按 Esc 同样先清空筛选，不立即退页。
6. 仅书签搜索保留无结果时 Enter 打开网址/网页搜索；命令无结果时不能执行模糊匹配或退回网页搜索。
7. 收起窗口时清空两处搜索；不清空编辑草稿、calc 算式、命令输入或后台任务。

### 文件夹与整理

- Enter 切换文件夹展开；→ 展开，← 折叠，子项上按 ← 折叠父文件夹并选中父项。
- `z` 全部展开/折叠；Esc 不再承担文件夹操作。
- `n` 新建文件夹，`e` 编辑书签或重命名文件夹，`m` 移动书签。
- `o` 进入/完成整理，Shift+↑↓ 排序；移除 J/K 排序别名。排序仍即时落盘，Esc 结束整理，不暗示撤销已保存顺序。
- 不改变同组排序、文件夹置顶和删除非空文件夹的现有限制。

## 5. calc 缓冲区

算式输入与历史列表分开焦点，但不增加另一套字母命令模式。

| 焦点 | 操作 |
| --- | --- |
| 算式 | Enter 计算；Tab 有历史时进入历史列表；文字编辑与选区交给原生控件 |
| 历史列表 | ↑↓ / Page Up/Down 选择，仅移动高亮；⌘C 复制该条结果 |
| 历史列表 | Enter 把选中算式载入输入，焦点回到算式；本次不重复计算、不新增历史 |
| 历史列表 | Esc 或 Shift+Tab 返回原算式草稿，不应用高亮项 |
| 算式 | Esc 返回主界面，保留算式与历史 |
| 命令覆盖层 | Esc 回到 calc 的原焦点、草稿和选择 |

calc 不再用裸 ↑↓ 回填历史，也不新增另一组历史回填快捷键。点击历史行只选择并聚焦历史；双击与 Enter 一样载入，避免鼠标和键盘采用不同草稿规则。

保留 `:calc clear`，作用仍为清空算式与历史；本轮不增加清理快捷键。计算能力、历史数量和运行期间保留规则不变。

## 6. 编辑与目录候选

### 编辑统一

书签新增/编辑与命令新增/编辑统一字段规则，继续复用底部输入区，不新增弹窗或整页表单：

- Tab / Shift+Tab 切字段，允许往返保留未提交草稿；↑↓ 不再切文本字段。
- 选项字段用 ←→ / Space 改值；不能修改隐藏字段。
- 文本或选项字段上 Enter / ⌘Enter 保存全部；移除“Enter 下一项，到末项又自动保存”的条件分支。
- 新增书签不再以连续 Enter 推进并最终保存；以 Tab 切 URL、标题、位置及必要的新文件夹名。沿用既有默认值规则，标题自动生成不得覆盖用户已编辑标题。
- 位置选择与新建文件夹视为字段/候选，不把 Shift+Tab 复用成另一套命令步骤栈。
- 保存统一校验所有有效字段；失败聚焦错误字段，保留其他草稿；成功落盘后才返回列表。
- Esc 取消未保存编辑；提示明确写“取消并丢弃草稿”，不写笼统“返回”。隐藏窗口不等于取消编辑。

### 目录候选简化

目录浏览由工作目录字段的 `⌘↓` 或“浏览目录”点击入口显式展开，候选不参与字段 Tab 顺序：

- `Tab / Shift+Tab` 始终下一／上一字段，工作目录不例外；进入路径字段时只显示输入和浏览入口，不自动显示或读取候选。
- 候选焦点：↑↓ 选择，→ 进入所选子目录，← 返回上一级。
- 列表提供明确的“使用当前目录”行，避免当前路径与高亮子目录混淆。
- Enter 采纳高亮目录或“使用当前目录”，立即收起候选并回到路径字段；仅修改草稿，不保存整个命令。随后 Tab 直接到下一字段，不重新打开候选。
- Esc 放弃本次目录浏览，收起候选并回到进入前的路径输入；浏览只改变候选位置，Enter 前不改路径草稿。
- 在目录浏览中按 Tab/Shift+Tab 同样切到下一/上一字段，收起候选且不应用高亮目录。关闭浏览时取消异步读取，过期结果不能重新显示候选。
- ⌘Enter 始终保存已采纳的字段值，不偷偷采纳正在高亮但尚未确认的候选。

目录浏览显式开启，字段导航和目录导航互不替代。书签位置／通用文件提示仍沿用各自的候选焦点；本次修正仅针对自定义命令工作目录。

## 7. 自定义命令与任务控制

- 命令列表沿用共同的列表、搜索、编辑和删除规则。
- ⌘D 创建副本草稿，操作文字统一叫“创建副本”；“复制”只用于剪贴板。
- Shift+D 进入删除确认，`y` 确认，`n / Enter / Esc` 取消；继续保留默认取消，不为了表面统一改成 Enter 删除。
- 执行页 Esc 返回命令列表，后台进程继续运行；键盘与点击“返回”调用同一动作。
- 新增明确的“停止任务”可点击动作及 ⌘.：仅在有本应用管理的后台进程时启用，先显示停止确认，`y` 确认，`n / Enter / Esc` 取消。
- 外部终端、浏览器和 Finder 已交接任务不显示可停止状态，不宣称能够终止外部会话。
- 返回列表后保留运行中状态与结果入口；不能因为退出执行页丢失停止入口或结果。仍保持同一时间只运行一条本应用后台命令的现有限制。
- 完成页 Page Up/Down 按整屏滚动；不再与 ↑↓ 一样只滚一行。

## 8. 命令入口、返回与提示

- 独立 `:` 命令输入继续使用 ↑↓ 选择、Tab/Shift+Tab 补全、⌥↑↓ 命令历史、Enter 执行、Esc 取消。
- 不自动执行仅按说明文字匹配的第一条结果；必须输入完整命令或显式选择候选。需要运行参数时可先 Tab 补全再输入参数。
- `:copy` 与当前页面对象复制使用同一目标解析；不得复制命令输入本身或隐藏书签。
- `:open / :edit / :delete / :move` 等涉及书签的命令在不适用页面明确提示作用域，不隐式关闭缓冲区后操作主列表。命令管理的运行与编辑通过该页动作执行。
- 从 calc/命令管理打开设置、帮助、日志时记录直接来源，关闭辅助页回到来源并恢复焦点；不引入通用、无限深的页面历史。
- 临时提示/命令输入先返回所属页面；calc 与命令管理关闭后回主界面；主界面 Esc 先结束筛选/整理等状态，随后收起。
- 当前有效动作同时驱动按键处理、菜单可用状态、点击动作和按键条，文案写明“复制网址 / 复制结果 / 创建副本 / 取消并丢弃草稿 / 返回列表 / 停止任务”。
- 仅显示当前焦点可执行的提示；不要在文本焦点下继续展示 `e`、`D` 等列表动作。

## 9. 实施顺序与改动边界

1. 整理统一的上下文与动作判断：以现有 `LauncherKeyRouter` 为入口，统一修饰键、输入法与字段编辑器优先级，不引入通用键位配置框架。
2. 对齐主列表/命令列表的搜索、复制、编辑与 Esc；移除失效别名并同步菜单和热键保留表。
3. 对齐 calc 历史焦点、字段编辑、目录候选与任务停止流程；键盘和鼠标复用同一动作。
4. 更新原生提示、命令帮助、`macos/README.md` 和相关测试契约，补原生输入验收，完成后更新 `macos/VALIDATION.md`。

实现主要涉及 `Application.swift`、`KeyboardShortcuts.swift`、`LauncherModel.swift`、`LauncherView.swift`、`TerminalCalc.swift`、`TerminalCustomCommands.swift`、`TerminalCustomCommandView.swift`、`TerminalCommands.swift`、`TerminalPrompts.swift`，以及对应测试。

不改 Windows、共享数据格式、命令执行参数规则、持久化位置、签名、安装或发布流程。网页原型不作为本次 macOS 验收替代品，也不为了本次方案重做原型。

## 10. 验收标准

- 两处搜索输入后按 ↓ 再输入字母，仍修改搜索词；按 Tab 后 e 编辑的必须是可见所选对象；Shift+Tab 回到原查询。
- 三页分别验证 ⌘C 的剪贴板内容；原生文本选区优先，命令复制不会创建副本，⌘D 不直接落盘。
- calc 输入未计算草稿，进入历史上下浏览、翻屏、复制、取消后草稿逐字不变；Enter 载入只载入一次，不写历史；再次 Enter 才计算。
- 预填编辑直接 Backspace 仅删一个字符；Tab/Shift+Tab 往返、中文组字、Shift 选区、⌥/⌘光标移动与撤销有效。
- 两类多字段编辑 Tab 不保存，Enter/⌘Enter 保存全部；校验失败保留所有字段；取消不落盘。
- 目录候选移动/进入/返回不改草稿；Enter 采纳准确目录；Esc/Tab 离开不意外采纳；中文、空格、相对路径和异步旧结果边界继续有效。
- 运行隔离后台测试进程：键盘 Esc 和点击返回均不停止；明确停止确认后才结束进程并显示实际退出状态；取消停止后进程仍存活。
- 主界面 Esc 不改变文件夹展开偏好；整理结束不撤销已保存顺序；辅助页回到正确来源。
- `:copy` 不访问隐藏书签；不适用页面的书签对象命令不改变数据或打开后台目标。
- 在真实 AppKit 事件循环、原生窗口和字段编辑器下验收焦点与输入，核对按键条及菜单；仅调用模型方法不能作为输入验收证据。
- 使用隔离目录与可控后台进程，不改正式数据、不终止用户程序、不安装或替换正式应用。

## 11. 用户影响

主要需要重新适应：c/C → ⌘C，命令副本 c → ⌘D，r → e；文件夹不再由 Tab/Esc 开合；calc 先选择历史再明确载入；字段导航改用 Tab，Esc 不再停止程序。

不保留有歧义的旧键位作为隐藏兼容入口，否则整改不能形成唯一契约。通过当前状态按键条和 macOS 使用说明明确新操作，不增加键位方案选择或兼容模式。
