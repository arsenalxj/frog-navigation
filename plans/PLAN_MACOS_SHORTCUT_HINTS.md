# macOS 快捷键提示精简方案

状态：已完成提示精简与自定义命令底部操作统一，并通过定向测试、原生界面及点击验收。保留现有键位、操作流程与点击能力，不添加“更多”菜单或其他新操作。

## 原则

- **同一动作只提示一次。** 已有按钮上标出的快捷键，不在其他位置重复。
- **只提示当前可用操作。** 编辑时不显示列表操作，搜索时不显示编辑操作。
- **每个动作只展示主键。** 例如 `Enter 保存`，不并列 `Enter / ⌘Enter`；其他有效键位仍保留在帮助中。
- **文案用“键位＋动作”。** 使用保存、打开、采纳、取消等明确短词，不写“保存／提交”等模糊组合。
- 主界面、calc、自定义命令的快捷键提示统一放在底部；自定义命令原有操作迁移后仍可点击，顶部不留副本。

## 各区域怎么改

| 区域 | 整改 |
| --- | --- |
| 输入行 | 只留字段名和输入内容，删除右侧快捷键串 |
| 上方提示区 | 只留关联信息、候选、错误和必要风险说明；删除重复按键教程与无意义标题 |
| 状态栏 | 只留页面、状态、结果数；编辑时不显示底层搜索信息 |
| 主界面／calc 底部 | 保留一组当前状态的必要快捷键，删除同义键堆叠 |
| 自定义命令 | 列表、搜索、编辑、目录浏览、删除及停止确认的提示与可点击操作统一到底部；顶部只保留内容、状态与数量 |

没有关联信息、候选或错误时，不画空提示框。输入行、状态栏的位置不变。

## 用户截图对应的结果

### 编辑标题

- 上方只保留关联网址或错误。
- 输入行只显示字段名、标题和光标。
- 状态栏只显示页面与编辑状态。
- 底部只留：`Tab/⇧Tab 切字段 · Enter 保存 · Esc 放弃修改`。

### 搜索

- 输入行只显示查询。
- 状态栏显示结果数。
- 底部只留：`↑↓ 选择 · Tab 进列表 · Enter 打开 · Esc 清空`。
- 空查询改为 `Enter 结束搜索`；无结果只保留实际可用动作。

## 其他状态

- **calc**：结果和历史区不写操作教程，快捷键只在底部出现。
- **自定义命令编辑**：保存、取消、字段导航和目录浏览入口统一到底部，保留点击能力。
- **目录浏览**：顶部只保留目录列表；导航、采纳、保存草稿和取消在底部各显示一次。
- **删除／停止确认**：正文只写目标和后果，确认和取消操作统一放在底部。
- **设置／帮助／日志**：标题不再重复返回、命令等快捷键；完整键表仍保留在帮助正文。

## 实施与验收

- 修改提示绘制和文案，不新增菜单、按钮、模式或配置，不调整按键路由。
- 删除输入行右侧提示时，一并清理占宽和旧命中区，让长网址、目录获得更多输入空间。
- 保留全部已有鼠标功能、错误反馈、危险操作后果和读屏说明。
- 用真实窗口检查：同一动作没有重复提示；文字不拥挤、不遮挡；原有键盘和鼠标操作不变。

实现与验收结果见 `macos/VALIDATION.md`；完整键位及有效别名仍见 `macos/README.md` 和应用帮助。
