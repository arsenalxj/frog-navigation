# 青蛙导航 Windows 原生终端方案

## 范围

按当前 macOS AppKit 回声终端对齐 Windows 11 x64 的界面与功能，保留 C++20、Win32、Direct2D / DirectWrite 原生技术栈。以 `macos/Sources/Frog/Terminal*.swift`、`LauncherView.swift`、`LauncherModel.swift` 为行为基准；布局与传统色来自 `designs/frog-echo-tui/SPEC.md`，树形展开以最新实现为准。

按用户明确要求，Windows **不实现文件夹快跳**：没有资源管理器监听、文件窗口浮条、对应设置项或 Ctrl+G 拦截。macOS 的 Finder 功能不变。

## 界面和输入

- 1440 × 900 全屏等比设计坐标，原生绘制传统色浅色终端；窗口覆盖屏幕，无独立任务栏入口。
- 文件夹置顶、原地展开；子书签缩进；19 行视口滚动而非分页。展开 ID 只存本机偏好。
- 底部原生 EDIT 保留 IME、光标、选区；输入、提示、任务各自拥有上下文快捷键。没有新增／编辑／设置表单弹窗。
- 添加三步、编辑双字段联合提交、重命名、移动候选、新组原子创建、删除确认、命令历史和路径补全。
- 设置、帮助、日志、任务、计算器使用全宽缓冲区；普通浏览显示最近三条日志。
- 本地首字符图标，UTF-16 ID 的乘31稳定散列与 macOS 同色；删除远程图标、缓存线程、壁纸、旧分页和拖拽状态模块，不保留旧界面分支。

## 行为

- 键盘与 macOS 一致，Command 等应用内组合映射为 Ctrl；Windows 全局默认组合仍为 Ctrl+Alt+Space。
- 列表点击后焦点回列表；提示流中背景点击不丢草稿；预填字段不自动全选；仅 Shift+Tab 回退。
- 搜索跨文件夹，打开默认浏览器成功后收起。整理只调整同组书签，文件夹固定，搜索结果不可排序。
- 鼠标整理支持前后插入、拖入文件夹、根书签停留550毫秒成组、边缘滚动和Esc取消。
- 计算器支持四则、括号、小数、指数、中文括号、256字上限、50条去重历史与12有效数字结果；关闭保留会话状态。
- Edge 默认扫描 Windows 稳定版数据目录，可指定数据目录、profile、Bookmarks；所有配置先完整校验再一次提交，保留空文件夹、精确URL去重，不修改源文件。

## 系统与数据

- 复用单实例、托盘、RegisterHotKey、当前用户登录启动快捷方式、被动屏幕触角。默认触角改为左下，已有偏好仍读取。
- 书签 JSON 契约不变：`frog-bookmarks` v1，UUID、创建时间、顺序、空组、根 `groupId:null` 保留。
- 保存经串行队列与原子替换，提交前比较磁盘快照；外部更新不原样写回；冲突载入新版本并保留草稿，用户明确重试。
- `:backup` 不改变主目录；`:restore` 整体替换；`:cd` 空目录复制当前数据，有效目录读取，失败保持原目录。
- `--data-directory` 隔离正式数据与偏好；`--background` 延迟创建窗口；`--diagnostics` 记录运行证据。无意义的旧 `--offline` 图标下载开关一并移除。

## 验证与交付

- `core`：模型、macOS fixture、存储、冲突、监听和热键。
- `terminal-features`：计算器边界和真实 Edge fixture 转换、去重、损坏及多配置全成功提交。
- `native-smoke`：真实进程、SendInput、UI Automation、磁盘内容与截图，覆盖命令提示、焦点、草稿、排序、计算器、备份恢复、目录切换和导入。必须在解锁的交互桌面执行，不用伪造输入替代通过结论。
- 产物仍为 `Frog.exe` 和 `Frog-windows-x64.zip`。安装／发布按用户当次授权，不自动修改正式安装。
- 最新实际结果见 `windows/VALIDATION.md`；旧 Launchpad 的图标缓存和性能记录只属于历史版本，不能作为终端版本的验收证据。
