# 青蛙导航 Windows 原生移植方案

## 目标与技术路线

- 首版支持 **Windows 11 x64**，迁移当前 macOS 应用的全部现有功能，排除 Finder 文件夹快速跳转。
- **只做全屏启动台**：无边框窗口铺满当前显示器工作区，保留任务栏，遵循任务栏自动隐藏设置。
- 使用 **C++20 + Win32 + Direct2D/DirectWrite**。网格和动画原生绘制，输入框、菜单及文件选择器采用 Windows 原生能力。重点控制启动、内存和后台开销。
- 应用源码、资源、测试、构建脚本和中文说明集中放在当前仓库的 `windows/`。实施时先建立目录规范，再开发；构建产物进入忽略目录。

## 功能与界面

保留 macOS 版的功能和主要布局，使用 Windows 字体、控件、快捷键及缩放规则。

- **主界面**：顶部搜索，右侧依次为设置和添加按钮；主体为书签、单层文件夹及分页圆点。文件夹内部保留添加入口。读取所在显示器壁纸并模糊，失败时使用系统主题背景。
- **书签管理**：新增、编辑、删除确认、复制网址、刷新图标、移动位置；文件夹支持重命名、排序和删除空文件夹。
- **整理操作**：长按整理、拖拽排序、跨页移动、移入／移出文件夹、拖动停留创建文件夹。取消拖拽恢复位置，成功放下后保存，写入失败回滚。
- **搜索与键盘**：搜索全部书签标题和网址，显示所属文件夹；方向键选择，Enter 打开选中结果，无结果时打开输入网址或 Google 搜索。支持鼠标滚轮、横向滚动、分页按钮和键盘翻页。
- **图标**：缓存优先、缺失时显示首字符、后台异步抓取；图标铺满容器。刷新失败保留旧图标，网络不阻塞启动、搜索和保存。
- **交互状态**：保留分页、文件夹开合和整理动效；Esc 逐层退出。普通收起保留编辑草稿，中文输入法组合输入期间不抢占确认、取消和方向键。

## Windows 系统适配

- **窗口生命周期**：每个用户运行一个实例。重复启动转交唤起请求；点击任务栏入口恢复现有窗口，重复点击导致的最小化转为收起。提供托盘菜单：展开／收起、设置、退出。
- **展开与收起**：在鼠标所在显示器展开；成功交给默认浏览器打开网址、切换到其他应用或点击根目录空白时收起。应用内菜单、编辑面板和系统文件选择器不触发误收起。`Alt+F4` 收起，完全退出通过托盘或设置。
- **快捷键**：默认 `Ctrl+Alt+Space`，使用 `RegisterHotKey`，支持修改、关闭、恢复默认及冲突提示；再次按下收起，长按不连续触发。应用内使用 `Ctrl+N` 添加、`Ctrl+,` 设置、`Ctrl+F` 或 `/` 搜索、`Page Up/Down` 翻页。
- **屏幕触角**：保留四角选择，Windows 版默认关闭。启用后通过被动鼠标事件驱动，进入一次只展开一次；拖动、文件选择器及切换动画期间抑制触发，静止时不轮询。
- **登录启动**：默认关闭，通过当前用户启动目录快捷方式运行 `--background`，静默驻留并延迟创建主界面。设置显示实际注册状态，提供 Windows“启动应用”入口处理系统禁用情况。
- **显示与辅助功能**：支持多显示器、负坐标、不同 DPI、显示器拔插及休眠恢复；尊重减少动画和高对比度设置，为自绘网格提供键盘导航及 UI Automation 支持。

## 数据、接口与资源控制

- 与 macOS 保持相同的 UTF-8 JSON：`format: "frog-bookmarks"`、`schemaVersion: 1`、`groups`、`bookmarks`。保留 ID、创建时间、逻辑顺序及根目录的 `groupId: null`，两端备份可互相读取。
- 默认主数据位于 `%LOCALAPPDATA%\Frog\Data\bookmarks.json`；偏好和图标缓存独立保存。自选数据目录只承载书签文件，可由坚果云等外部工具同步。
- 保留目录切换、另存备份及完整恢复语义：空目录复制当前数据，有效目录直接读取；恢复校验通过后整体替换，不合并。格式错误、目录不可用或写入失败时保留原数据。
- 所有保存经串行存储模块完成，使用临时文件和原子替换；保存前检查磁盘快照。通过 `ReadDirectoryChangesW` 监听外部更新，遇到冲突保留草稿并要求重试。
- 界面只维护当前页和必要的相邻页；图标按显示尺寸解码、限制缓存和网络并发。收起后停止动画、取消无用请求并释放大型图像及绘制资源。
- 保留 `--background`、`--offline`、`--data-directory`、`--diagnostics`，用于隔离测试和性能采样；隔离运行不修改日常偏好及登录启动配置。

## 实施顺序与验收

1. **工程与数据层**：建立 CMake/MSVC 工程、目录规范和测试；完成模型、原子存储、目录监听、备份恢复及 macOS 数据兼容。
2. **完整启动台**：实现全屏布局、搜索、文件夹、表单、图标、分页及拖拽，并完成状态恢复和输入法处理。
3. **系统集成**：完成单实例、任务栏、托盘、快捷键、屏幕触角、登录启动和多显示器适配。
4. **构建与交付**：提供 Windows 构建检查流程、x64 Release ZIP、用户级安装／卸载脚本及中文说明；更新保留用户数据。

验收覆盖：

- macOS 导出 → Windows 编辑导出 → macOS 读取，确认中文、空文件夹、ID、归属和顺序保持一致。
- 离线完整操作、损坏数据、外部原子替换、目录丢失、保存失败及图标缓存失效。
- 全屏任务栏行为、反复唤起、Alt+Tab、中文输入法、连续拖拽、不同 DPI、多屏、休眠恢复和实际登录启动。
- 在用户的 Windows 电脑上测量 Release：以 1,000 条本地书签为基准，目标为新进程启动到可操作 **≤1 秒**、再次展开 **≤150 毫秒**、收起 30 秒后私有提交内存 **≤50 MB**、静置平均 CPU **≤0.5%**。同时记录硬件、工作集和图形资源占用。
- Windows 编译结果、真实交互和性能分别记录证据，自动测试不替代 Windows 实机验收。实施环境与实际结果记录于 `windows/VALIDATION.md`。
